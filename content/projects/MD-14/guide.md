# MD-14 对由运放器组成的积分运算电路、微分运算电路

## 实训目的

1. 掌握集成运放反相积分运算电路将方波变换为线性三角波的机理及时间常数 $RC$ 定量计算。
2. 掌握集成运放实用微分运算电路将三角波变换为方波的机理，理解串联阻尼电阻的稳健性作用。
3. 观察积分与微分电路的输入输出相位与斜率对应关系。

## 实训原理

1. **反相积分运算电路**：
   输入电阻 $R_1 = 10\ \text{k}\Omega$、反馈电容 $C = 22\ \text{nF}$（并联 $500\ \text{k}\Omega$ 直流稳定电阻），输出满足：
   $$u_o(t) = -\frac{1}{R_1 C}\int u_i(t)\,dt$$
   输入幅值 $\pm U_m = \pm 2\ \text{V}$、频率 $f = 1\ \text{kHz}$（$T/2 = 0.5\ \text{ms}$）的对称方波时，输出为反相线性三角波，理论峰峰值：
   $$\Delta U_o = \frac{U_m \cdot (T/2)}{R_1 C} = \frac{2 \times 0.5\ \text{ms}}{10\ \text{k}\Omega \times 22\ \text{nF}} \approx 4.55\ \text{Vpp}$$
2. **实用反相微分运算电路**：
   输入为电容 $C = 22\ \text{nF}$（串联 $470\ \Omega$ 抑振电阻），反馈电阻 $R_f = 20\ \text{k}\Omega$：
   $$u_o(t) = -R_f C \frac{du_i(t)}{dt}$$
   输入 $500\ \text{Hz}$、$4\ \text{Vpp}$ 三角波（斜率 $\pm 4000\ \text{V/s}$）时，输出为规则方波，理论峰峰值 $\approx 3.52\ \text{Vpp}$。

## 器材清单

- `mod-opamp` 集成运放与波形发生综合挂箱（区 1 运放与 22 nF 微积分电容支路）
- 直流稳压电源（CH1 + CH2 构成 ±12 V 双电源）
- 双通道函数信号发生器、双通道数字示波器（仪表柜）

## 实训步骤

1. 保持断电，拖放信号发生器与示波器；直流电源设 `±12 V`，信号源 CH1 设 `1 kHz`、`4 Vpp` 方波。
2. **积分实验（方波→三角波）**：按图接 `CH1 → OA1_IN1`、`OA1_C1 → OA1_SUM`、`OA1_C2 → OA1_OUT`、`OA1_PIN → GND2`，点击“检查接线”。上电观测输出三角波并记录至 `int_diff` 第 1 行。
3. **微分实验（三角波→方波）**：断电改接 `CH1 → OA1_C1`、`OA1_C2 → OA1_SUM`、`OA1_FB → OA1_OUT`，信号源改设为 `500 Hz`、`4 Vpp` 三角波，点击“检查接线”。上电观测方波输出并记录第 2 行。
4. 断电后核对曲线并完成思考题。

## 注意事项

- 积分实验切忌输入过高直流偏置，否则输出容易触及正负电源轨导致三角波削顶。
- 改接电容从反馈支路移至输入支路前必须先断电。

## 思考题

1. 输入正弦波信号分别送入反相积分电路与反相微分电路时，输出与输入之间的相位差各是多少度？
2. 为什么实用微分电路不能省略电容支路串联的小阻尼电阻，否则在输入方波跳变沿会产生什么现象？
3. 若想把 `1 kHz`、`4 Vpp` 方波积分输出的三角波幅值由 `4.5 Vpp` 减半为 `2.25 Vpp`，改变电阻 `R1` 或频率 `f` 分别应如何调整？
