# MD-09 直流稳压正、负电源电路的研究

## 实训目的

1. 掌握中心抽头双绕组变压器配单只整流桥同时生成正、负对称双电源的工作原理。
2. 掌握固定正三端稳压器（LM7812）与固定负三端稳压器（LM7912）的典型应用电路搭建与对称性测试。
3. 实测双路稳压电源的负载调整率与输入纹波抑制能力，理解双电源在运放与音频功放电路中的必要性。

## 实训原理

1. **中心抽头桥式正负整流**：
   变压器副边为双 15 Vrms 对称绕组，中心抽头 `AC_CT` 直接作为公共参考地 `GND`。当 `AC_S1` 为正半周时，电流经桥堆正端为正滤波电容充电至 $+20\ \text{V}$，同时 `AC_S2` 为负半周经桥堆负端为负滤波电容充电至 $-20\ \text{V}$；下一半周两臂交替工作，在 `+Ui` 与 `−Ui` 端同时获得 100 Hz 对称全波脉动直流。
2. **LM7812 / LM7912 固定正负稳压**：
   正未稳压端 `+Ui`（约 $+20\ \text{V}$）送入 LM7812，稳压输出 $+12.00\ \text{V}$；负未稳压端 `−Ui`（约 $-20\ \text{V}$）送入 LM7912，稳压输出 $-12.00\ \text{V}$。输入与输出保持约 $8\ \text{V}$ 压差，远高于 $2\ \text{V}$ 最小压差门槛。
3. **负载调整率**：
   定义负载调整率 $S_I = \frac{|U_{o(\text{空载})} - U_{o(\text{满载})}|}{U_{o(\text{空载})}} \times 100\%$。在 `0 → 100 mA`（`120 Ω`）负载变化范围内，未稳压端 `+Ui` 明显跌落且纹波增大，而 LM7812 输出变化小于 $0.1\ \text{V}$（$S_I < 1\%$）。

## 器材清单

- `mod-analog-base` 模拟电路综合实验挂箱（220 V / 15 V×2 中心抽头变压器）
- `mod-power-reg` 整流滤波稳压实验板（全波桥、对称双 470 µF 滤波、LM7812、LM7912、可调负载 `SW_RLOAD`）
- 三相调压交流电源（单相 220 V）、直流数字电压表（固定控制屏）；数字万用表、双通道数字示波器（仪表柜）

## 实训步骤

1. 保持断电，拖放数字万用表与示波器；交流电源设相电压 `220 V`，`SW_CFILT` 置 `470 µF`，`SW_RLOAD` 置 `空载 (10 kΩ)`。
2. 断电按图接线：`U/N → AC_P1/AC_P2`、`AC_S1 → AC_1`、`AC_S2 → AC_2`、`AC_CT → REG_GND`；`RECT_P → REG78_IN`、`RECT_N → REG79_IN`、`REG78_OUT → LOAD_IN`；固定直流电压表测 `+12V / GND`，万用表直流 `20 V` 档测 `−12V / GND`，点击“检查接线”。
3. **空载对称性验证**：上电记录空载 `+12V` 与 `−12V` 实际读数（误差 ≤ 1%）至 `dual_supply` 表第 1 行，并用万用表核实未稳压端 `+Ui / −Ui` 约 `±20 V`。
4. **带载调整与纹波对比**：带电将 `SW_RLOAD` 依次切至 `轻载 (240 Ω)` 与 `满载 (120 Ω)`，记录第 2、3 行数据并计算负载调整率；用示波器 AC 耦合对比 `RECT_P` 纹波与 `REG78_OUT` 稳压后纹波。
5. 断电核对曲线，完成思考题。

## 注意事项

- 本实验为双电源共地架构，`RECT_N` 是 `-20 V` 负电源输入端，**严禁**像 MD-08 那样将 `RECT_N` 短接到 `REG_GND`，否则会直接短路负半周整流桥！
- 测量负电源输出时保持黑表笔（`COM`）接 `REG_GND`、红表笔接 `REG79_OUT`，表上自然显示负值 `-12.00 V`。
