# DG-03 未知电阻的测定—非线性电路的研究、白炽灯灯丝温度的测定及单臂电桥电路的应用

## 实训目的

1. 掌握单臂惠斯通电桥（Wheatstone Bridge）的原理与调零平衡操作方法，准确测定未知线性电阻 $R_x$ 与白炽灯冷态电阻 $R_{20}$。
2. 测定 $12\ \text{V} / 0.1\ \text{A}$ 钨丝白炽灯在不同工作电压下的热态电阻 $R(U)$，结合冷态电阻换算灯丝工作温度。
3. 理解非线性正温度系数器件的自热机理及微电流冷态测量的重要性。

## 实训原理

1. **单臂电桥平衡条件**：元件箱内置等比例精密上臂 $R_1 = R_2 = 1000\ \Omega$，左下臂接入待测电阻 $R_x$，右下臂接入可调十进制电阻箱 $R_{\text{box}}$，对角线 $B\text{–}C$ 跨接指针式检流计 $G$。当检流计电流 $I_g = 0$ 时电桥平衡：

$$\frac{R_1}{R_2} = \frac{R_x}{R_{\text{box}}} \implies R_x = \frac{R_1}{R_2} R_{\text{box}} = R_{\text{box}}$$

2. **白炽灯冷态电阻与灯丝温度换算**：在 $2\ \text{V}$ 低桥压与 $1\ \text{k}\Omega$ 桥臂限流下，流过白炽灯的电流不足 $2\ \text{mA}$（功耗 $< 50\ \mu\text{W}$），灯丝温升可忽略，测得即室温 $T_0 = 293.15\ \text{K}$（$20\ ^\circ\text{C}$）下的冷态电阻 $R_{20} \approx 12.0\ \Omega$。通电发光后，钨丝热态电阻满足经验幂律：

$$R(T) = R_{20} \left(\frac{T}{T_0}\right)^{1.2} \implies T = T_0 \left(\frac{R_{\text{hot}}}{R_{20}}\right)^{1/1.2}, \qquad t = T - 273.15\ ^\circ\text{C}$$

以上公式仅用于原理分析与手动换算校核，不替代真实电路仿真与测量。

## 实训步骤

1. **选表准备**：断电从仪表柜拖放指针式检流计至桌面空闲位。
2. **电桥测未知电阻 $R_x$**：CH1 设 $6\ \text{V}$；连线 `CH1P → BR_P`、`BR_L → RX_1`、`BR_R → RBOX_1`、`RX_2 / RBOX_2 / BR_N → CH1N`，检流计正负端接 `BR_L` / `BR_R`。检查接线后上电，调节 `RBOX` 直至检流计指针归零（$|I_g| \le 2\ \mu\text{A}$），将 $R_{\text{box}}$ 与 $I_g$ 记入 `bridge_balance` 第 1 行。
3. **电桥测白炽灯冷阻 $R_{20}$**：断电并将 CH1 调至 $2\ \text{V}$，将左下臂待测件改接为 `EL_1` / `EL_2`，检查接线后上电调节 `RBOX` 使检流计指零（约 $12.0\ \Omega$），记录至 `bridge_balance` 第 2 行。
4. **伏安法测热态电阻**：断电拆除电桥与检流计连线，按 `CH1P → IM_IN`、`IM_OUT → EL_1`、`EL_2 → CH1N` 接线，固定电压表并 `EL_1`/`EL_2`，固定毫安表串 `IM_A`/`IM_B`。检查接线后上电，在 $2, 4, 6, 8, 10, 12\ \text{V}$ 六点记录 $U$、$I$ 至 `filament_temp` 表（自动算出 $R_{\text{hot}} = U/I$），并手工换算各点灯丝温度 $t$。
5. **整理分析**：断电查看 $R\text{–}U$ 曲线并回答思考题。

## 注意事项

- 测白炽灯冷阻前务必先将电源电压降至 $2\ \text{V}$ 再上电，防止大电流自热导致冷阻读数偏高。
- 检流计满偏量程仅 $\pm 100\ \mu\text{A}$，初步平衡时可先大致估算 $R_{\text{box}}$ 数值再微调至 `0.1 Ω` 级。
- 断电后再拆除或切换电桥/伏安法接线。

2. 在 $1:1$ 比例臂（$R_1 = R_2 = 1\ \text{k}\Omega$）惠斯通电桥中，检流计内阻大小会影响平衡条件吗？会影响平衡检测灵敏度吗？
