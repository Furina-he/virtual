# DG-02 电路元件伏安特性的测绘

## 实训目的

1. 掌握用直流电压表与毫安表逐点测绘线性及非线性二端元件伏安特性（$I\text{–}U$ 曲线）的实验方法。
2. 对比定值线性电阻（$1\ \text{k}\Omega$）、钨丝白炽灯（$12\ \text{V} / 0.1\ \text{A}$）、硅整流二极管（`1N4007`）与硅稳压二极管（`2CW51`）的伏安特性差异。
3. 理解正温度系数电阻、单向导电死区电压、齐纳反向击穿稳压及串联限流保护的物理意义。

## 实训原理

1. **线性电阻 $R_A$**：严格遵守欧姆定律 $I = U / R_A$，$I\text{–}U$ 曲线为过原点的直线，斜率恒定为 $1 / R_A = 1\ \text{mS}$。
2. **白炽灯 $EL_1$**：钨丝具有正温度系数，随功率增大灯丝温度从室温 $20\ ^\circ\text{C}$ 升至近 $1724\ ^\circ\text{C}$，阻值由冷态约 $12\ \Omega$ 升至额定热态 $120\ \Omega$，曲线呈上凸（电流增速变缓）对称非线性。
3. **硅二极管 `1N4007`**：正向导通满足肖克莱指数规律 $I_F \approx I_S \left(e^{U_F / (n U_T)} - 1\right)$，正向压降约 $0.6\sim 0.8\ \text{V}$ 后电流急剧上升，必须串联 $R_{\text{lim}} = 220\ \Omega$ 限流保护。
4. **稳压二极管 `2CW51`**：正向与普通硅管类似；反向电压达到齐纳击穿电压 $U_Z \approx 3.3\ \text{V}$ 后电流陡增而端电压几乎不变，动态电阻 $r_z = \Delta U_Z / \Delta I_Z$ 很小。以上公式仅作原理分析与误差校核，所有表格数据均须由真实仿真逐点采集。

| 设备/模块 | 型号或规格 | 作用 |
| --- | --- | --- |
| 直流稳压电源（固定） | CH1 $0\sim 30\ \text{V}$ / $1\ \text{A}$ | 提供可调直流激励电压 |

## 实训步骤

1. **初始配置**：断电将直流电压表设 `20 V` 档（`10 MΩ`），毫安表设 `200 mA` 档（测 `RA` 与二极管小电流时可改用 `20 mA` 档提高分辨力）。
2. **测绘线性电阻 $R_A$**：连接 `CH1P → IM_IN`、`IM_OUT → RA_1`、`RA_2 → CH1N`，电压表并 `RA_1`/`RA_2`，毫安表串 `IM_A`/`IM_B`；检查接线后上电，在 $2, 4, 6, 8, 10\ \text{V}$ 五点记录至 `vi_resistor` 表。
3. **测绘白炽灯 $EL_1$**：断电改接被测元件为 `EL_1`/`EL_2`，电压表改并 `EL_1`/`EL_2`，检查接线后上电，依次设 `CH1 = 2, 4, 6, 8, 10, 12 V`，逐点记录至 `vi_lamp` 表。
4. **测绘 `1N4007` 正向特性**：断电串入 `RLIM`（`CH1P → RLIM_1`、`RLIM_2 → IM_IN`、`IM_OUT → VD_A`、`VD_K → CH1N`），电压表并 `VD_A`/`VD_K`，检查接线后上电，依次设 `CH1 = 0.5, 0.7, 1.0, 2.0, 5.0, 10.0 V`，记录至 `vi_diode` 表。
5. **测绘 `2CW51` 反向击穿特性**：断电改接为反向偏置（`IM_OUT → VZ_K`、`VZ_A → CH1N`），电压表正端接 `VZ_K`、负端接 `VZ_A`，检查接线后上电，依次设 `CH1 = 1, 2, 3, 4, 5, 6 V`，记录至 `vi_zener` 表。
6. **曲线对比分析**：断电后打开底栏“曲线”页签对比四条 $I\text{–}U$ 曲线形态，回答思考题。

## 注意事项

- 测绘 `1N4007` 与 `2CW51` 时**务必串联 $220\ \Omega$ 限流电阻 `RLIM`**，切勿将直流电源直接加在半导体 PN 结两端。
- 测绘白炽灯时最高电压不超过额定 $12\ \text{V}$；切换被测支路前须先**断电**。
- 在二极管小电流区与大电流区可根据需要切换毫安表 `20 mA` / `200 mA` 档，同时注意记录表电流列统一以 **A** 为单位。

## 思考题

1. 比较线性电阻与白炽灯的伏安特性曲线，为什么白炽灯曲线随电压升高逐渐向电压轴弯曲？
2. `1N4007` 二极管与 `2CW51` 稳压管的导通拐点分别出现在哪个工作象限？为什么测绘时必须串入 $220\ \Omega$ 限流电阻？
3. 稳压管工作在反向击穿区时，动态电阻 $r_z = \Delta U_Z / \Delta I_Z$ 越小说明其稳压性能越好还是越差？
4. 在伏安特性测绘中，电压表应采用内接法还是外接法？对 $1\ \text{k}\Omega$ 电阻与 $12\ \text{V}$ 白炽灯分别如何选择？
