# DG-09 戴维南定理和电桥电路的应用——铜电阻温度计电路的研究（综合）

## 实训目的

1. 验证戴维南定理：测定含独立电压源与恒流源的线性有源二端网络的开路电压 $U_{oc}$、短路电流 $I_{sc}$ 及等效内阻 $R_{eq}$，并通过扫测不同负载电阻箱 $R_L$ 下的端电压与电流验证端口等效性。
2. 搭建基于 `Cu50` 铜热电阻的非平衡惠斯通测温电桥，完成 $0\ ^\circ\text{C}$ 零点平衡与 $0\sim 100\ ^\circ\text{C}$ 温度–电压标定。
3. 运用戴维南定理分析非平衡电桥的输出灵敏度与仪表加载影响，并练习双挂箱系统的直流故障定位。

## 实训原理

1. **有源二端网络戴维南等效**（`dc1` 下半部：$R_6 = 330\ \Omega, R_7 = 510\ \Omega, R_8 = 10\ \Omega, R_9 = 510\ \Omega$，$U_s = 12\ \text{V}, I_s = 10\ \text{mA}$）：
   将内部独立源置零（$U_s$ 短路、$I_s$ 开路），从端口 $A\text{–}B$ 看入的等效内阻与开路电压为：

$$R_{eq} = (R_6 \parallel R_7) + R_8 + R_9 \approx 200.36 + 520 = 720.36\ \Omega$$

$$U_{oc} = U_s \frac{R_7}{R_6 + R_7} + I_s \bigl((R_6 \parallel R_7) + R_8\bigr) \approx 7.286 + 2.104 = 9.39\ \text{V}, \qquad I_{sc} = \frac{U_{oc}}{R_{eq}} \approx 13.03\ \text{mA}$$

2. **Cu50 铜电阻非平衡电桥温度计**（`comp1`：$R_1 = R_2 = 1000\ \Omega$，$R_{\text{box}} = 50.0\ \Omega$，$U_E = 6.0\ \text{V}$）：
   工业 Cu50 热电阻在 $0\sim 100\ ^\circ\text{C}$ 满足线性分度关系 $R_{\text{Cu}}(t) = 50.00 \cdot (1 + 4.28 \times 10^{-3} t) = 50 + 0.214 t\ (\Omega)$。在 $0\ ^\circ\text{C}$ 时 $R_{\text{Cu}} = R_{\text{box}} = 50.0\ \Omega$，电桥平衡 $U_{BC} = 0\ \text{V}$；当温度升至 $t$ 时，空载桥压为：

$$U_{BC}(t) = U_E \left(\frac{R_{\text{Cu}}(t)}{R_1 + R_{\text{Cu}}(t)} - \frac{R_{\text{box}}}{R_2 + R_{\text{box}}}\right) \approx 0\sim 114.1\ \text{mV}$$

以上公式仅作理论校核，所有实验数据均须由真实仿真逐点读取。

## 实训步骤

1. **戴维南参数测定（$U_{oc}$ 与 $I_{sc}$）**：断电设 CH1 $= 12\ \text{V}$、恒流源 `20 mA` 档设 `10 mA`，连接 `CH1P → dc1.TH_USP`、`CH1N → dc1.TH_USN`、`ISP → dc1.TH_ISP`、`ISN → dc1.TH_ISN`；点击“检查接线”。上电用直流电压表（`20 V` 档）测 `dc1.TH_A`/`TH_B` 得 $U_{oc} \approx 9.39\ \text{V}$；断电拆电压表，用毫安表（`20 mA` 档）测端口短路电流 $I_{sc} \approx 13.03\ \text{mA}$（因网络内部串有 $R_9 = 510\ \Omega$，不会短路电源），算得 $R_{eq} = U_{oc} / I_{sc} \approx 720.4\ \Omega$。
2. **有源二端网络带载验证**：断电跨挂箱连接 `dc1.TH_A → comp1.RBOX_1`、`dc1.TH_B → comp1.RBOX_2`；电压表并 `TH_A`/`TH_B`，毫安表串入 `dc1.TH_IA`/`TH_IB`，检查接线后上电，依次调节 `comp1.RBOX` 为 `200, 500, 720, 1000, 2000 Ω`，记录至 `thevenin_load` 表。
3. **Cu50 测温电桥标定**：断电拆除全部接线，将 CH1 调至 $6\ \text{V}$、恒流源断开不用；在 `comp1` 连接 `CH1P → BR_P`、`BR_L → CU_1`、`BR_R → RBOX_1`、`CU_2 / RBOX_2 / BR_N → CH1N`，设 `RBOX = 50.0 Ω`；将固定电压表切至 `200 mV` 档并接 `BR_L`（+）与 `BR_R`（−），检查接线后上电。依次将 `T_CU50` 旋钮设为 `0, 20, 40, 60, 80, 100 ℃`，将温度与实测 $U_{BC}$（单位 **V**）记入 `cu50_temp` 表。
4. **曲线分析与排故**：断电查看两条特性曲线，完成思考题，并可在右栏“排故”页签进行 3 项预设故障定位。

## 注意事项

- 切换阶段 1（双挂箱戴维南网络）与阶段 2（Cu50 电桥）时务必先**断电**并清空旧连线，避免 $12\ \text{V}$ 或恒流源误接入电桥。
- 测温电桥满量程输出约 $114.1\ \text{mV}$，使用直流电压表 `200 mV` 档可获 $0.1\ \text{mV}$ 高分辨力；注意记录表电压列统一以 **V** 为单位（例如 `57.6 mV` 记为 `0.0576 V`）。
- 测短路电流 $I_{sc}$ 仅适用于本网络经内部 $R_9$ 限流的输出端 `TH_A`/`TH_B`，严禁将毫安表直接接至电源 `CH1+`/`CH1−`。

## 思考题

1. 如何仅用一次开路电压测量与一次带载电压测量（半电压法）求出有源二端网络的戴维南等效内阻 $R_{eq}$？
2. 将非平衡电桥从对角线 $B$、$C$ 处断开，用戴维南定理求该测温电桥在 $t = 50\ ^\circ\text{C}$ 时的等效电动势与等效内阻。
3. 为什么 `Cu50` 测温电桥在 $0\sim 100\ ^\circ\text{C}$ 区间输出电压 $U_{BC}$ 与温度 $t$ 近似呈线性关系？增大上臂电阻 $R_1, R_2$ 对非线性误差与灵敏度各有何影响？
4. 如果将电桥输出接至输入内阻仅 $10\ \text{k}\Omega$ 的电压表（而非 $10\ \text{M}\Omega$），测得的温度计灵敏度会怎样变化？
