# MD-19 RC（文氏桥式）正弦波振荡器的制作与调试

## 实训目的

1. 掌握 RC 串并联（文氏桥）选频网络的幅频与相频特性及正弦振荡相位/幅值起振条件。
2. 定量验证振荡频率公式 $f_0 = \frac{1}{2\pi R C}$（1.0 kHz / 2.0 kHz 双频切换）。
3. 掌握反并联二极管非线性负反馈稳幅机理，对比停振、稳定正弦与过驱动削顶三种状态。

## 实训原理

1. **文氏桥选频与起振条件**：
   串并联 RC 网络取 $R_1 = R_2 = R = 10\ \text{k}\Omega$、$C_1 = C_2 = C$（`15.9 nF` 或 `7.96 nF`）。在谐振频率：
   $$f_0 = \frac{1}{2\pi R C}$$
   处网络相移严格为 $0^\circ$，正反馈传输系数达到最大值 $F_m = \frac{1}{3}$。因此同相放大电路闭环增益必须满足 $A_v = 1 + \frac{R_{\text{fb}}}{R_g} > 3$（即 $R_{\text{fb}} > 2 R_g = 20\ \text{k}\Omega$）方能自激起振。
2. **反并联二极管自动稳幅**：
   负反馈支路由 `RF_WIEN`（默认 `17 kΩ`）串联 `8.2 kΩ || (D1N4148 反并联)` 组成：
   - 起振初期振幅极小，二极管截止，$R_{\text{fb}} = 17 + 8.2 = 25.2\ \text{k}\Omega$，$A_v = 3.52 > 3$，迅速起振；
   - 振幅增长后二极管导通分流，等效反馈电阻自动向 `17 kΩ`（$A_v = 2.7 < 3$）回落，最终平衡在环路增益 $|A_v F| = 1$ 的低失真稳定正弦波。

## 器材清单

- `mod-opamp` 集成运放与波形发生综合挂箱（区 4 文氏桥振荡区：`OA5`、`RF_WIEN`、`SW_WIEN_C`、反并联 `1N4148`）
- 直流稳压电源（CH1 + CH2 串联 ±12 V）
- 双通道数字示波器、数字万用表（仪表柜）

## 实训步骤

1. 保持断电，拖放数字示波器；设 `±12 V` 双电源，`RF_WIEN` 置 `17 kΩ`，`SW_WIEN_C` 置 `1.0 kHz (15.9 nF)`。
2. 断电按图接好 `±12 V` 供电并短接 `OA_VP → WIEN_EN`，示波器 `CH1 → WIEN_OUT`、`CH2 → WIEN_P`、`GND → OA_GND2`，点击“检查接线”。
3. **起振与稳幅测试**：上电先设 `RF_WIEN = 11 kΩ` 观察停振；再调至 `17 kΩ` 观测纯净稳定 `1.0 kHz` 正弦波（记录第 1 行）及 `CH1 / CH2` 同相 3:1 幅值比；可再调至 `23 kΩ` 对比过驱动削顶失真。
4. **双频换档**：调回 `RF_WIEN = 17 kΩ`，带电将 `SW_WIEN_C` 切至 `2.0 kHz (7.96 nF)`，核实频率翻倍至约 `2000 Hz` 并记录第 2 行。
5. 断电核对曲线，完成思考题。

## 注意事项

- 文氏桥振荡器必须将 `WIEN_EN` 短接至 `OA_VP`（+12 V）方能供电起振。
- 调小 `RF_WIEN` 停振后，再次调大起振需等待约几十毫秒建立稳态振幅。

## 思考题

1. 为什么在稳幅电路中必须采用两只二极管反并联，而不能只接入一只单向二极管？
2. 当实测 `WIEN_OUT` 为 1.00 kHz、6.0 Vpp 纯正弦波时，`WIEN_P` 端波形的频率、相位与峰峰值理论上分别是多少？
3. 除二极管稳幅外，工程上还常用热敏电阻（NTC/PTC）或场效应管压控电阻做文氏桥稳幅，它们对谐波失真（THD）有何改进？
