# DG-19 一阶电路暂态过程的研究

## 实训目的

1. 用周期方波激励替代单次机械开关，在数字示波器上稳定观测一阶 RC 与 RL 电路的零状态响应和零输入响应。
2. 掌握利用示波器双光标测量一阶电路时间常数 $\tau$（上升至 $0.632 U_m$ 或衰减至 $0.368 U_m$ 所用时间）的方法。
3. 验证 $\tau_{RC} = R_{\text{total}} C$ 与 $\tau_{RL} = L / R_{\text{total}}$ 的理论规律，理解电阻对 RC 与 RL 暂态过程快慢的不同影响。

## 实训原理

1. **一阶 RC 电路暂态过程**：
   当方波半周期 $T/2 \ge 5\tau$ 时，每个半周期内电容均近似完成充分充放电：
   - 充电（零状态响应）：$u_C(t) = U_m (1 - e^{-t/\tau})$，当 $t = \tau$ 时 $u_C(\tau) = 0.632 U_m$；
   - 放电（零输入响应）：$u_C(t) = U_m e^{-t/\tau}$，当 $t = \tau$ 时 $u_C(\tau) = 0.368 U_m$。
   计入信号发生器 $50\ \Omega$ 输出内阻，当 $C_t = 0.1\ \mu\text{F}$、$R_t = 1 / 5 / 10\ \text{k}\Omega$ 时，理论 $\tau = (R_t + 50\ \Omega) C_t = 0.105 / 0.505 / 1.005\ \text{ms}$。
2. **一阶 RL 电路暂态过程**：
   $L = 10\ \text{mH}$（内阻 $5\ \Omega$）串联 $R_s = 51\ \Omega$ 与信号源 $50\ \Omega$ 内阻，总电阻 $R_{\text{total}} = 106\ \Omega$，时间常数 $\tau = \frac{L}{R_{\text{total}}} \approx 94.3\ \mu\text{s}$。通过测量串联电阻电压 $u_R(t) = i_L(t) R_s$ 即可直接观测电感电流的指数过渡过程。

## 器材清单

- `mod-rlc-transient` 动态电路与 RLC 综合实验挂箱（Rt = 1/5/10 kΩ、Ct = 0.1 µF、L = 10 mH、Rs = 51 Ω）
- 双通道函数信号发生器、双通道数字示波器（从仪表柜拖放）

## 实训步骤

1. 保持断电，拖放函数信号发生器与数字示波器；设 CH1 为 `100 Hz` 方波、`4 Vpp`、`2 V` 直流偏置（即 0 ↔ 4 V），设 `SW_TAU_R = 1 kΩ`、`SW_TAU_C = 0.1 µF`。
2. 阶段 1（RC 暂态）：连接 `CH1→TR_1`、`TR_2→TC_1`、`TC_2→GND`；示波器 CH1 接 `TR_1`、CH2 接 `TC_1`、GND 接 `TC_2`，点击“检查接线”。
3. 上电并调节示波器时基（`200 µs/div` ~ `1 ms/div`），使用垂直/水平双光标测量 $u_C$ 从 0 V 上升至 $0.632 \times 4 \approx 2.53\ \text{V}$ 的时间 $\Delta t = \tau$；依次切换 `SW_TAU_R = 1`、`5`、`10 kΩ` 记录实测 $\tau$ 与输出 $V_{pp}$。
4. 阶段 2（RL 暂态）：断电改接 `CH1→LS_1`、`LS_2→RS_1`、`RS_2→GND`（`SW_RLC_R = 51 Ω`），示波器 CH1 接 `LS_1`、CH2 接 `RS_1`、GND 接 `RS_2`，点击“检查接线”。将方波频率升至 `1 kHz`，用光标测取电阻端电压 $u_R$ 指数上升时间常数（约 `94 µs`）。
5. 断电后核对 $\tau - R$ 线性关系图并完成思考题。

## 注意事项

- 必须采用示波器 **DC 耦合** 观测零状态/零输入暂态电平（AC 耦合会隔断直流偏置并引入额外高通畸变）。
- 测量 $R_t = 10\ \text{k}\Omega$（$\tau \approx 1.0\ \text{ms}$）时，方波半周期 $T/2$ 需不小于 $5\ \text{ms}$（频率 $\le 100\ \text{Hz}$），确保充电充分达到稳态。

## 思考题

1. 为什么在用示波器观测一阶电路暂态过程时，需满足激励方波半周期 $T/2 \ge 5\tau$？
2. 实测 $R_t = 1\ \text{k}\Omega$ 时 $\tau \approx 0.105\ \text{ms}$ 略大于 $1\ \text{k}\Omega \times 0.1\ \mu\text{F} = 0.100\ \text{ms}$，请从信号源输出阻抗角度解释原因。
3. 增大电阻 $R$ 时，一阶 RC 电路过渡变慢而一阶 RL 电路过渡变快，请从储能元件泄放回路阻抗角度解释。
