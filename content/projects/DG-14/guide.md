# DG-14 R、L、C 串联谐振电路的研究

## 实训目的

1. 测定 RLC 串联电路的谐振频率 $f_0$，验证理论公式 $f_0 = \frac{1}{2\pi\sqrt{LC}}$。
2. 测绘不同电阻（品质因数 $Q$）下的幅频谐振曲线，理解 $Q$ 值对曲线尖锐度与通频带 $\Delta f = f_0 / Q$ 的影响。
3. 验证串联谐振时“电压谐振”放大现象（$U_C \approx U_L \approx Q U_{\text{in}}$）。

## 实训原理

在电阻 $R$、电感 $L = 10\ \text{mH}$（绕组内阻 $r_L = 5\ \Omega$）、电容 $C = 0.1\ \mu\text{F}$ 串联电路中，复阻抗为：
$$Z(\omega) = R_{\text{total}} + j\left(\omega L - \frac{1}{\omega C}\right)$$
当 $\omega_0 L = \frac{1}{\omega_0 C}$ 时，电抗抵消、阻抗最小且呈纯阻性，电路发生串联谐振：
$$f_0 = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{10^{-2}\times 10^{-7}}} \approx 5032.9\ \text{Hz}$$
特征阻抗 $\rho = \sqrt{L/C} = 316.23\ \Omega$。计入信号源内阻 $50\ \Omega$、电感内阻 $5\ \Omega$ 与挂箱串联电阻 $R_s$：
- 高 $Q$ 档（$R_s = 51\ \Omega$）：回路总电阻 $106\ \Omega$，总品质因数 $Q_{\text{tot}} \approx 2.98$（以挂箱端口电压 $U_{\text{in}}$ 计则 $Q_{\text{port}} = 316.2 / 56 \approx 5.65$），2 Vpp 激励下谐振点 $U_C \approx 2.11\ \text{V}_{\text{rms}}$；
- 低 $Q$ 档（$R_s = 150\ \Omega$）：回路总电阻 $205\ \Omega$，总品质因数降至 $1.54$，谐振峰值大幅压低、曲线明显变宽。

## 器材清单

- `mod-rlc-transient` 动态电路与 RLC 综合实验挂箱（Rs 51/150 Ω、L=10 mH、C=0.1 µF）
- 双通道函数信号发生器、双通道交流毫伏表、双通道数字示波器（从仪表柜拖放）

## 实训步骤

1. 保持断电，拖放函数信号发生器、交流毫伏表与示波器；将挂箱 `SW_RLC_R` 设为 `51 Ω`（高 Q 档），信号源 CH1 设为正弦波 `2 Vpp`、`5033 Hz`。
2. 断电连线：`generator1.CH1` → `RS_1`、`RS_2` → `LS_1`、`LS_2` → `CS_1`、`CS_2` → `generator1.GND`；交流毫伏表 CH1 接 `CS_1`、GND 接 `CS_2`，点击“检查接线”。
3. 上电验证谐振峰：在 `5033 Hz` 附近微调频率确认 $U_C$ 达到极大值（约 `2.11 Vrms`），远高于输入电压有效值（约 `0.36 Vrms`）。
4. 扫频测绘谐振曲线：依次设定频率 `2500`、`3500`、`4500`、`5033`、`5600`、`6800`、`8500 Hz`，将各点 $U_C$ 记入 `resonance_curve` 表；随后将 `SW_RLC_R` 切至 `150 Ω` 对比谐振峰回落（约 `1.09 Vrms`）与带宽展宽。
5. 断电后查看谐振曲线，计算半功率带宽与实测 $Q$ 值，完成思考题。

## 注意事项

- 交流毫伏表输入为共地单端测量，跨接电容 `CS_1`/`CS_2` 时 `CS_2` 已接信号源 `GND`，可直接读取电容电压；若改测 `U_R` 请注意不要用接地表笔短接电感与电容。
- 每次改频后等待约 0.5 s 待交流毫伏表有效值稳定再记录。

## 思考题

1. 串联谐振时电容电压 $U_C$ 与电感电压 $U_L$ 大小近乎相等、相位相差约 $180^\circ$，为什么它们可以远大于电源电压？
2. 增大回路电阻 $R_s$ 对 $f_0$、$Q$ 值和通频带 $\Delta f$ 分别有什么影响？
3. 工程上如何利用高 $Q$ 串联谐振选频，又如何防止电力系统中发生串联谐振过电压？
