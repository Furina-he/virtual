# SD-06 七段码锁存/译码/驱动器功能测试

## 实训目的

1. 掌握 `CD4511` BCD-七段锁存/译码/驱动器的 0~9 译码规则及 10~15 非法码消隐特性。
2. 掌握灯测端 `/LT`、消隐端 `/BI` 与锁存使能端 `LE` 的控制逻辑及优先级。
3. 掌握数码管缺段、消隐短路、灯测短路三类典型数字显示故障的测量诊断与排除方法（FLT-04）。

## 实训原理

`CD4511` 内部由四位电平敏感 D 锁存器、8421 BCD 七段译码器与 NPN 射极跟随高电平段驱动级构成，适配**共阴极**七段数码管：

- **锁存控制（`LE`）**：`LE = 0` 时锁存器透明，输出实时跟随 $DCBA$；`LE = 1` 时锁存当前 BCD 码，屏蔽后续输入变化。
- **灯测与消隐（`/LT`、`/BI`）**：`/LT = 0` 时强制七段全亮显示“8”，且优先级高于 `/BI`；当 `/LT = 1` 且 `/BI = 0` 时全灭消隐。
- **正常译码（`/LT = 1, /BI = 1`）**：输入 `0000~1001` 显示 `0~9`；输入 `1010~1111` 输出全 0 自动消隐。每段经 $330\ \Omega$ 限流电阻驱动数码管对应字段。

## 器材清单

- 固定直流稳压电源（`ins-dc-power`，+5 V 端）
- 固定直流数字电压表（`ins-dc-voltmeter`）或数字万用表（`ins-multimeter`）
- 基本逻辑门与译码显示实验箱（`mod-dig-gates`），内置 `CD4511`、共阴七段数码管、开关 `K0~K5` 及 3 处预设故障单元

## 实训步骤

1. 断电连接 `ins-dc-power.V5P` → `dg1.VCC`、`ins-dc-power.V5N` → `dg1.GND`，并将 `dg1.K0~K3` 接至 `CD_A~CD_D`、`K4` → `CD_LT`、`K5` → `CD_BI`、`GND` → `CD_LE`，点击“检查接线”。
2. 保持 `SW_K4=1`、`/BI`（`SW_K5=1`），上电依次拨动 `SW_K0~K3` 验证 `0000~1001` 对应显示 `0~9`、`1010~1111` 全灭，并测记显示 `0` 时 `CD_SEGA` 电压（约 3.2 V）。
3. 置 `SW_K4=0`（`/LT=0`）验证无论输入或 `/BI` 状态如何，数码管均显示“8”；恢复 `SW_K4=1` 后置 `SW_K5=0` 验证消隐全灭。
4. 断电将 `CD_LE` 改接 `VCC`（`LE=1`）或配合开关切换，验证锁存功能。
5. 切至右栏“排故”面板，按“观察现象 → 测电压定位 → 提交诊断 → 修复验证”完成三类显示故障演练，最后断电完成思考题。

## 注意事项

- 测量 `CD_SEGA` 电压判别缺段故障前，请先确保当前输入码对应数字点亮 a 段（如 `0`、`2`、`3`、`5`、`7`、`8`、`9`，注意 `1` 和 `4` 本身不点亮 a 段）。
- 排故完成后须点击修复并重新上电验证 `u_sega`/`u_bi`/`u_lt` 恢复正常范围。

## 思考题

1. 当 `CD4511` 的 `/LT` 与 `/BI` 同时接低电平时，数码管显示全亮“8”还是全灭？这说明两者的控制优先级如何？
2. `CD4511` 输入 `1010~1111`（十进制 10~15）时为何主动消隐？工程上在多位数码管显示中有什么好处？
3. `CD4511` 与共阴极数码管之间为什么要串联 330 Ω 限流电阻？若其中 a 段限流电阻开路，数字 `0`、`1`、`7`、`8` 分别会呈现出什么缺段现象？
