# DG-01 电气仪表的使用和测量误差的计算

## 实训目的

1. 掌握控制屏固定直流稳压电源、直流数字电压表、直流数字毫安表与台式数字万用表的正确选档、极性与接线方法。
2. 通过串联分压电路定量测定不同输入内阻电压表（$10\ \text{M}\Omega$、$10\ \text{k}\Omega$、$1\ \text{k}\Omega$）和不同量程电流表引入的加载误差，理解仪表内阻对被测电路的影响。
3. 验证超量程溢出提示（`OL.`）、反接极性显示、错档联锁保护与断电电阻测量的规范操作流程。

## 实训原理

在 `mod-dc-components` 元件箱上构建由 $R_B = 2\ \text{k}\Omega$ 与 $R_C = 10\ \text{k}\Omega$ 组成的串联分压电路，直流电源 $U_s = 12\ \text{V}$。未接电压表时，$R_C$ 两端理论开路电压及端口戴维南等效内阻为：

$$U_0 = U_s \cdot \frac{R_C}{R_B + R_C} = 12 \times \frac{10}{2 + 10} = 10.00\ \text{V}, \qquad R_{\text{th}} = R_B \parallel R_C = \frac{2 \times 10}{12} \approx 1.667\ \text{k}\Omega$$

当输入内阻为 $R_v$ 的直流电压表并联在 $R_C$ 两端时，表内阻与 $R_C$ 并联使端电压跌落，实测值与相对方法误差为：

$$U_m = U_0 \cdot \frac{R_v}{R_{\text{th}} + R_v}, \qquad \gamma = \frac{U_m - U_0}{U_0} \times 100\% = -\frac{R_{\text{th}}}{R_{\text{th}} + R_v} \times 100\%$$

类似地，将内阻为 $R_A$ 的直流毫安表串入电流插座 `I` 时，回路电流由 $I_0 = U_s / (R_B + R_C) = 1.000\ \text{mA}$ 变为 $I_m = U_s / (R_B + R_C + R_A)$。以上公式仅作原理校核，软件不向仪表或表格预填理论值，所有读数均由 `ngspice` 实时求解得出。

| --- | --- | --- |

| 电路基础实验挂箱（二）/元件箱 | `mod-dc-components`（`comp1`） | 提供 $R_B = 2\ \text{k}\Omega$、$R_C = 10\ \text{k}\Omega$ 与常闭电流插座 `I` |

| 数字万用表（仪表柜自选） | `ins-multimeter`（DCV/DCA/Ω） | 练习选表、错档保护检查与断电测电阻 |

## 实训步骤

1. **准备与选表**：保持断电，将 CH1 设为 $12\ \text{V}$、限流 $1\ \text{A}$；从右侧仪表柜选取数字万用表放到桌面空闲位。
2. **搭建分压电路**：连接 `ins-dc-power.CH1P → comp1.IM_IN`、`comp1.IM_OUT → comp1.RB_1`、`comp1.RB_2 → comp1.RC_1`、`comp1.RC_2 → ins-dc-power.CH1N`，点击“检查接线”。
3. **电压表加载误差测试**：将固定直流电压表（`20 V` 档）正负端分别接 `comp1.RC_1`、`comp1.RC_2`。上电后依次在 `10 MΩ`、`10 kΩ`、`1 kΩ` 三种输入内阻下读数，将数据填入 `meter_error` 表并填写理想开路值 `10`，观察自动计算的相对误差 $\gamma$。
4. **超量程与反接验证**：恢复 `10 MΩ`，将量程切换为 `2 V` 档观察 `OL.`；切回 `20 V` 档并断电反接测量线，上电确认负值读数后断电恢复。
5. **电流表量程内阻对比**：断电拆去电压表外线，将直流毫安表正负端接 `comp1.IM_A`、`comp1.IM_B`，先后选 `2 mA` 档（内阻 $100\ \Omega$）与 `20 mA` 档（内阻 $10\ \Omega$）上电记录电流至 `current_range` 表。
6. **万用表错档与无源电阻测量**：断电拆除固定表外线，将万用表 `VΩ`/`COM` 接 `RC_1`/`RC_2`，先验证直流电流档接电压孔时的错档拦截提示；随后保持断电并切至 `20 kΩ` 电阻档，实测 $R_C$ 阻值。

## 注意事项

- 改接或拆除任何导线前必须先点击**断电**，避免带电操作触发安全警告。
- 直流电流表仅可串入电流插座 `IM_A`/`IM_B`（两线均接入后内部常闭短接自动断开），严禁直接并联在电源或电阻两端。
- 使用数字万用表电阻档、二极管档或通断档时，被测支路必须完全断电；若回路带电，仪表将自动拦截测试源注入并告警。

## 思考题

1. 为什么在 $2\ \text{k}\Omega / 10\ \text{k}\Omega$ 高阻分压回路中，电压表内阻从 $10\ \text{M}\Omega$ 降为 $1\ \text{k}\Omega$ 时读数大幅偏低？
2. 已知电源等效内阻 $R_{\text{th}}$ 与电压表内阻 $R_v$，如何定量计算接入电压表引入的方法相对误差？
3. 在测量约 $1\ \text{mA}$ 的微弱直流电流时，$2\ \text{mA}$ 档与 $20\ \text{mA}$ 档在分辨率和分流电阻压降误差上应如何权衡？
4. 为什么严禁用电流档并联测量电源或元件两端电压，且电阻档必须在断电条件下使用？
