# DG-08 叠加定理的验证与应用——多信号叠加控制电路的研究（综合）

## 实训目的

1. 验证线性双电源直流电路中各支路电流与节点电压满足叠加定理（齐次性与可加性），掌握独立电压源置零（短接）的规范操作。
2. 通过将挂箱开关 $K_3$ 切换至硅二极管 `1N4007`（$VD_1$），实验证实含非线性元件的电路不满足叠加定理。
3. 理解叠加定理仅适用于线性电路中的电压和电流分量，而不适用于功率的直接叠加。

## 实训原理

在 `mod-dc-circuit` 上半部双电源网络中：
- 当 $K_3 = 0$ 时，支路 $D\text{–}C$ 接入线性电阻 $R_5 = 330\ \Omega$，全网络为线性电路。令 $U_1$ 单独作用（$K_1=1, K_2=0$，即 $B$ 与 $C$ 短接将 $U_2$ 置零）测得分量 $I_k', U_{AD}'$；令 $U_2$ 单独作用（$K_1=0, K_2=1$，即 $F$ 与 $E$ 短接将 $U_1$ 置零）测得分量 $I_k'', U_{AD}''$；双源共同作用（$K_1=1, K_2=1$）测得总响应 $I_k, U_{AD}$，必满足：

$$I_k = I_k' + I_k'' \quad (k = 1, 2, 3), \qquad U_{AD} = U_{AD}' + U_{AD}''$$

但电阻功耗为二次非线性量，$P_3 = I_3^2 R_3 = (I_3' + I_3'')^2 R_3 = P_3' + P_3'' + 2 I_3' I_3'' R_3 \ne P_3' + P_3''$。
- 当 $K_3 = 1$ 时，支路 $D\text{–}C$ 切入单向导电的非线性二极管 `1N4007`（阳极接 $D$、阴极接 $C$），在不同电源单独作用时二极管工作在截然不同的偏置状态（正向导通或反向截止），故总响应与各分量之和出现巨大偏差。以上公式仅作原理校核，数据均须实测记录。

## 实训步骤

1. **初始设定与接线**：保持断电，CH1 设 $6\ \text{V}$、CH2 设 $12\ \text{V}$，连接 `CH1P → KH_U1P`、`CH1N → KH_U1N`、`CH2P → KH_U2P`、`CH2N → KH_U2N`，点击“检查接线”。
2. **线性工况 1（$U_1$ 单独作用）**：设挂箱控件 `K1=1, K2=0, K3=0`。分次测量 $I_1', I_2', I_3'$（毫安表 `20 mA` 档，每次只接一处电流插座）与 $U_{AD}'$（拆去毫安表后用电压表 `20 V` 档测），记录至 `superposition_linear` 第 1 行。
3. **线性工况 2（$U_2$ 单独作用）**：设 `K1=0, K2=1, K3=0`，按相同方法测得 $I_1'', I_2'', I_3''$ 与 $U_{AD}''$，记录至第 2 行。
4. **线性工况 3（双源共同作用）**：设 `K1=1, K2=1, K3=0`，测得总响应 $I_1, I_2, I_3$ 与 $U_{AD}$ 记入第 3 行，核对代数和误差（应 $\le 1\%$）。
5. **非线性反例验证（$K_3=1$）**：将 `K3` 切换为 `1`（接入 `1N4007`），分别在（`K1=1, K2=0`）、（`K1=0, K2=1`）、（`K1=1, K2=1`）三种工况下测量并记入 `superposition_nonlinear` 表，对比叠加偏差。
6. **分析与排故**：断电整理数据，完成思考题并可在右栏“排故”页签练习 3 个典型直流故障定位。

## 注意事项

- 任何时候都不得用导线将 $U_1$ 或 $U_2$ 电源输出端直接短接；电源置零必须通过挂箱上的 $K_1$、$K_2$ 开关实现（将电路端与电源断开并改接至内部短路回线）。
- 测量 $I_1, I_2, I_3$ 与 $U_{AD}$ 时必须严格保留正负号（按参考方向 $F\to A$、$A\to B$、$A\to D$ 接入表笔正负端）。
- 每次移动电流表或电压表表线前均应先**断电**。

## 思考题

1. 验证叠加定理使不作用的独立电压源置零时，为什么要将电源支路“短路”（保留内阻）而不是“开路”？
2. 根据线性表中的两组单独作用电流与共同作用电流，计算 $R_3$ 消耗的功率 $P_3$，验证功率为什么不能直接叠加？
3. 当 $K_3$ 切至二极管 $VD_1$（$K_3=1$）时，为什么 $U_1$ 单独作用、$U_2$ 单独作用与双源共同作用不再满足叠加关系？
4. 若电路中含有独立电流源，令该电流源单独置零时应对其作何处理？
