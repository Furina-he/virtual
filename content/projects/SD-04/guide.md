# SD-04 全加器和超前进位全加器功能测试

## 实训目的

1. 掌握一位二进制全加器 `74LS183` 的真值表与逻辑表达式。
2. 掌握四位二进制超前进位全加器 `74LS283` 的运算功能，理解超前进位相比串行逐位进位的速度优势。

## 实训原理

1. **一位全加器（`74LS183`）**：对本位加数 $A, B$ 与来自低位的进位 $C_i$ 求和：
   $$S = A \oplus B \oplus C_i, \qquad C_o = AB + (A \oplus B)C_i$$
2. **四位超前进位全加器（`74LS283`）**：定义各位的进位生成项 $G_i = A_i B_i$ 与进位传播项 $P_i = A_i \oplus B_i$，直接展开各级进位：
   $$C_4 = G_4 + P_4 G_3 + P_4 P_3 G_2 + P_4 P_3 P_2 G_1 + P_4 P_3 P_2 P_1 C_0$$
   所有进位并行由输入端一步生成，大幅缩短高位运算延迟。

## 器材清单

- 固定直流稳压电源（`ins-dc-power`，+5 V 端）
- 固定直流数字电压表（`ins-dc-voltmeter`）或数字万用表（`ins-multimeter`）
- 全加器与数值比较器实验箱（`mod-dig-arith`），内置 `SN74LS183`、`SN74LS283`、开关 `K0~K3`、四位操作数旋钮 `OP_A`/`OP_B` 及板载 `H/L` 指示灯

## 实训步骤

1. 断电连接 `ins-dc-power.V5P` → `ar1.VCC`、`ins-dc-power.V5N` → `ar1.GND`，再连接 `ar1.K0` → `FA_A`、`K1` → `FA_B`、`K2` → `FA_CI` 及 `AD4_C0`，点击“检查接线”。
2. 上电后拨动 `SW_K0/K1/K2` 依次验证 `74LS183` 全部 8 组输入组合，观察 `183 和 S` 与 `183 进位 Co` 的 `H/L` 状态并记录关键状态电压。
3. 置 `SW_K2=0`（$C_0=0$），确认默认 `OP_A=5`、`OP_B=3` 时 `74LS283` 输出 $S_3S_2S_1S_0 = 1000$（十进制 8）、$C_4=0$。
4. 调 `OP_A=9`、`OP_B=6` 并置 `SW_K2=1`（$C_0=1$），验证满进位传播使 $S_3S_2S_1S_0 = 0000$、$C_4=1$（总和 16）；再置 `OP_A=15`、`OP_B=15`、`SW_K2=1` 验证最大输出 31（`1111` + `C4=1`）。
5. 断电完成数据核对与思考题。

## 注意事项

- 读取 `74LS283` 四位和数时注意位权顺序：`S3` 为最高位（权重 8），`S0` 为最低位（权重 1），`C4` 权重为 16。
- 实测全进位链（如 `15 + 0 + 1` 或 `9 + 6 + 1`）时务必确认 `SW_K2` 已切换至高电平。

## 思考题

1. 串行进位加法器（多片 `74LS183` 级联）在位数增多时的主要性能瓶颈是什么？`74LS283` 超前进位如何消除这一瓶颈？
2. 如何利用 `74LS283` 四位全加器和四只异或门（`74LS86`）实现四位二进制减法 $A - B$（补码运算）？
3. 当 `OP_A=9`、`OP_B=6` 且低位进位 $C_0=1$ 时，`74LS283` 内部每一位的进位生成信号 $G_i$ 与传播信号 $P_i$ 分别如何作用使 $C_4=1$？
