# DG-07 实际直流稳压电源和直流稳流电源的研究（综合）

## 实训目的

1. 分别测绘含内阻实际直流电压源与含并联内阻实际直流电流源的外特性曲线（$U\text{–}I$）。
2. 通过对比相同外接负载 $R_L$ 下的端口电压与电流，实验验证电压源与电流源的等效变换条件（戴维南–诺顿互换）。
3. 理解稳压电源的恒压/限流（CV/CC）特性与恒流源的开路顺从电压保护机理。

## 实训原理

实际直流电压源可等效为理想电压源 $E$ 与内阻 $R_0$ 的串联；实际直流电流源可等效为理想电流源 $I_s$ 与内阻 $R_0$ 的并联。当二者满足：

$$E = I_s R_0, \qquad R_{0,\text{电压源}} = R_{0,\text{电流源}} = R_0$$

时，它们对外接任意负载 $R_L$ 具有完全相同的伏安关系（外特性直线）：

$$U = E - I R_0 = I_s R_0 - I R_0$$

本项目取 $E = 10.0\ \text{V}$、$R_0 = 100\ \Omega$，其诺顿等效电流源为 $I_s = E / R_0 = 100.0\ \text{mA}$ 并联 $R_0 = 100\ \Omega$。注意“等效”仅对外电路成立，内部功耗在开路或短路时完全不同。以上公式仅作校核参考，表格读数须由仿真实验采集。

## 实训步骤

1. **参数预置**：保持断电，设 `SW_R0 = 100 Ω`，电压表置 `20 V` 档，毫安表置 `200 mA` 档。
2. **实际电压源外特性测绘**：CH1 设 $10\ \text{V}$；连线 `CH1P → R0_1`、`R0_2 → IM_IN`、`IM_OUT → RBOX_1`、`RBOX_2 → CH1N`；电压表并 `RBOX_1`/`RBOX_2`，毫安表串 `IM_A`/`IM_B`；检查接线后上电，在 `RBOX = 50, 100, 200, 500, 2000 Ω` 五点记录至 `vs_char` 表。
3. **实际电流源外特性测绘**：先**断电**拆除 CH1 导线，在直流稳压电源面板将恒流源档位切至 `500 mA` 档、电流设为 `100 mA`；连接 `ISP → R0_1 → IM_IN`、`IM_OUT → RBOX_1`、`R0_2 / RBOX_2 → ISN`（保持电压表与毫安表不变），检查接线后上电，在完全相同的 `50, 100, 200, 500, 2000 Ω` 五点记录至 `cs_char` 表。
4. **等效性比对**：断电核对 `vs_char` 与 `cs_char` 对应行的 $U$ 与 $I$（相对差异应在 $1\%$ 以内），并在底栏“曲线”页签查看两条重合的斜率为 $-100\ \Omega$ 的外特性直线。

## 注意事项

- 切换电压源与恒流源前必须先**断电**并拆清 `CH1` 导线，切勿将电压源与恒流源同时接入同一节点。
- 使用恒流源 `Is = 100 mA` 时请先确认量程已选至 `500 mA` 档（默认的 `20 mA` 档会限制最大输出为 `20 mA`）。
- 若负载开路且未并联 $R_0$，恒流源输出端电压会钳位在约 $30\ \text{V}$ 顺从保护上限并触发开路提示。

## 思考题

1. 对比实际电压源与实际电流源的 $U\text{–}I$ 外特性曲线，两者满足什么参数关系时对外电路完全等效？
2. 电源等效变换是对外部电路等效还是对电源内部也等效？分别计算开路状态下两种模型内部的功耗。
3. 若把本实验中实际电流源的并联电阻 $R_0$ 拆去（变为理想恒流源），开路时恒流源两端电压会出现什么保护现象？
4. 实验室直流稳压电源面板上的 CV（恒压）与 CC（恒流）指示灯在什么负载条件下发生自动切换？
