# DG-12 交流电路功率及功率因数的测量及提高线路功率因数的方法及其意义的研究

## 实训目的

- 掌握单相交流电路中功率表、交流电压表与交流电流表的正确接法及同名端规则。
- 通过在 50 Hz 感性负载（30 W 日光灯与电感镇流器稳态等效模型）两端并联不同容量的补偿电容，验证线路总电流先减小后增大、功率因数先提高后降低（过补偿）以及负载有功功率基本不变的规律。
- 利用真实仿真测量数据绘制 $\cos\varphi\text{–}C$ 与 $I\text{–}C$ 特性曲线，理解无功补偿在工程节电与设备扩容中的意义。

## 实训原理

原理图见“原理图”标签页（点击插孔可与 3D 台面双向高亮联动）。

本项目挂箱 `mod-ac-fluorescent` 采用 50 Hz、220 V 稳态等效感性负载支路：铁芯镇流器等效串联电阻 $R_b = 60\ \Omega$、电感 $L_b = 1.65\ \text{H}$（$X_L = 2\pi f L_b \approx 518.36\ \Omega$），日光灯管稳态电阻 $R_{\text{lamp}} = 240\ \Omega$，总串联阻抗：

$$Z_{RL} = R + j X_L = 300 + j\,518.36\ \Omega,\qquad |Z_{RL}| \approx 598.92\ \Omega.$$

在交流电压有效值 $U = 220\ \text{V}$ 条件下，未加补偿（$C = 0$）时：

$$I_{RL} = \frac{U}{|Z_{RL}|} \approx 0.3673\ \text{A},\qquad P = I_{RL}^2 R \approx 40.48\ \text{W},\qquad \cos\varphi_0 = \frac{R}{|Z_{RL}|} \approx 0.501.$$

并联补偿电容 $C$ 后，负载端电压 $U$ 不变，感性支路电流 $\dot{I}_{RL}$ 与有功功率 $P$ 基本不变，而电容容性无功电流 $\dot{I}_C = j\omega C \dot{U}$ 抵消感性无功分量，总导纳与功率因数满足：

$$Y = G + j(\omega C - B_L),\qquad \cos\varphi = \frac{G}{\sqrt{G^2 + (\omega C - B_L)^2}}.$$

当 $\omega C = B_L$（理论最佳补偿 $C_{\text{opt}} \approx 4.60\ \mu\text{F}$，挂箱提供 $C_3 = 4.7\ \mu\text{F}$）时，$\cos\varphi \approx 1.00$，线路总电流降至最小（约 $0.184\ \text{A}$）；继续增大电容至 $6.9\ \mu\text{F}$ 或 $7.9\ \mu\text{F}$ 时进入**过补偿**状态，无功功率 $Q < 0$（容性 `C`），总电流重新增大且 $\cos\varphi$ 回落。上述公式仅用于理论校核，软件不向仪表或表格预填理论值。

## 实训步骤

1. **检查初始状态**：台面保持断电，确认补偿电容开关 `KC1`、`KC2`、`KC3` 均处于“断开”状态，交流电源相电压设定为 `220 V`。
2. **连接主回路与仪表**：断电连接 `ins-ac-power.U → ac1.AC_L`、`ins-ac-power.N → ac1.AC_N` 及 `ac1.LOAD_IN → ac1.CAP_IN`；将交流电流表串入总电流插座 `I_LINE_A`/`I_LINE_B`，将功率表电流端 `I`/`*I` 串入 `I_TOT_A`/`I_TOT_B`，将功率表电压端 `U`/`*U` 与交流电压表 `U`/`*` 并联至 `LOAD_IN` 与 `AC_N`。点击“检查接线”确认通过。
3. **测量未补偿态（`C = 0 µF`）**：上电等待 50 Hz 瞬态有效值与功率窗口稳定，在记录表第 1 行填入电容 `0` 并快捷记录 `U`、`I`、`P`、`Q`、`cosφ`。
4. **分级投入补偿电容**：依次在运行中切换电容开关至 `2.2 µF`（仅 `KC2`）、`3.2 µF`（`KC1+KC2`）、`4.7 µF`（仅 `KC3` 最佳补偿）与 `7.9 µF`（`KC1+KC2+KC3` 过补偿），每档等待功率窗口刷新稳定后记录至下一空行。
5. **曲线观察与分析**：断电后切换至底栏“曲线”页，观察 `cosφ–C` 曲线与 `I–C` V 形曲线，结合公式列视在功率 $S = U \cdot I$ 分析补偿效果并完成思考题。

## 注意事项

- **先断电再改线**：带电插拔交流 220 V 回路导线会被安全联锁拦截；电容组开关 `KC1~KC3` 支持运行中连续切换并自动刷新有效值窗口。
- **严防电流线圈并联**：交流电流表与功率表电流线圈均须串联在对应电流插座内，严禁跨接电源 `U`–`N` 两端。
- **核对功率表同名端**：功率表 `I` 端接电源侧、`*I` 端接负载侧，`U` 端接火线侧、`*U` 端接零线侧；若接反会导致有功功率与功率因数变负。
- **模型边界说明**：本挂箱采用 50 Hz 稳态线性感性负载与理想开关电容等效模型，未模拟启辉器击穿辉光与荧光粉非线性谐波；仪表内阻与准确度等级为原型估计参数。

## 思考题

1. 在感性负载两端并联补偿电容后，负载支路的有功功率 P 与电流 I_RL 为什么基本保持不变，而线路总电流 I 显著减小？
2. 从 I–C 与 cosφ–C 曲线可以看出，并联电容是否越大越好？过补偿（如 7.9 µF）会带来什么现象与后果？
3. 单相功率表接线时为什么必须核对电压线圈与电流线圈的同名端（U/*U、I/*I）？若电流线圈反接，读数会如何变化？
4. 工业供电中提高功率因数对变压器容量利用率与输电线路损耗有哪些实际意义？
