# MD-13 运算放大器基本运算电路

## 实训目的

1. 掌握集成运放（LM324 / μA741）在线性区的“虚短”和“虚断”分析方法。
2. 搭建并定量验证反相比例、同相比例、反相加法及差分减法四种基本运算电路的输入输出关系（误差 ≤ 1%）。
3. 观察输入过大时的电源轨输出饱和现象，并演练运放反馈开路与参数漂移排故。

## 实训原理

1. **反相比例运算**：
   $R_{\text{in1}} = 10\ \text{k}\Omega$、$R_f = 20\ \text{k}\Omega$，同相端经平衡电阻接地，闭环增益：
   $$A_{vf} = -\frac{R_f}{R_{\text{in1}}} = -2.00$$
2. **同相比例运算**：
   输入接同相端 `OA1_P`，`OA1_IN1` 接地，闭环增益：
   $$A_{vf} = 1 + \frac{R_f}{R_{\text{in1}}} = +3.00$$
3. **反相加法与差分减法**：
   - 双输入经 `R_in1 = R_in2 = 10 kΩ` 接入反相求和点：$u_o = -2(u_1 + u_2)$。
   - `u_1` 接 `OA1_IN1`，`u_2` 经同相分压 `R_p1 = 10 kΩ / R_p2 = 20 kΩ` 接入 `OA1_PIN`：$u_o = 2(u_2 - u_1)$。
4. **输出饱和**：
   当理论输出超过运放电源轨摆幅（±12 V 供电下约 $-11.95\ \text{V}\sim +10.5\ \text{V}$）时，进入非线性限幅区，“虚短”失效。

## 器材清单

- `mod-opamp` 集成运放与波形发生综合挂箱（区 1 线性运算区，预置 3 项故障点）
- 直流稳压电源（CH1 + CH2 串联 ±12 V）
- 双通道函数信号发生器、双通道数字示波器、数字万用表（仪表柜）

## 实训步骤

1. 保持断电，拖放函数信号发生器与示波器；直流电源设 `CH1 = 12 V`、`CH2 = 12 V` 并接 `CH1− → CH2+ → OA_GND1` 形成 ±12 V 双电源，信号源设 `1 kHz`、`2 Vpp` 正弦波。
2. **反相比例（−2×）**：接 `RF → UO1`、`PIN → GND2`、`CH1 → IN1`，示波器测 `IN1` 与 `UO1`，点击“检查接线”。上电记录 `4.0 Vpp` 反相输出，再把输入增至 `14 Vpp` 观察削顶饱和。
3. **同相比例（+3×）**：断电改接 `IN1 → GND2`、`CH1 → OA1_P`，上电记录 `6.0 Vpp` 同相输出。
4. **反相加法与差分减法**：分别按图接入双路信号 `CH1 / CH2` 至 `IN1 / IN2`（加法）与 `IN1 / PIN`（减法），核对和差幅值与相位。
5. 断电核对数据表，可在“排故”面板演练运放 3 项预设故障，最后完成思考题。

## 注意事项

- 搭建 ±12 V 双电源时务必确认 `CH1−` 与 `CH2+` 短接作地，`CH1+` 接 `+12V`，`CH2−` 接 `−12V`，切勿反接电源极性。
- 改接反相/同相/加法线路前必须先断电。

## 思考题

1. 在反相比例放大器中，若实测反相端 `OA1_SUM` 对地交流电压接近 0 mV，这体现了运放的什么特性？
2. 同相比例放大器的输入电阻与反相比例放大器的输入电阻相比，哪一种更高？为什么？
3. 若需要把反相加法器的输出改为 $u_o = -(u_1 + 2u_2)$，应如何选择 `R_in1`、`R_in2` 与 `R_f` 的阻值比例？
