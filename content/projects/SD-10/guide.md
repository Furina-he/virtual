# SD-10 二位十进制计数/译码/驱动/显示电路

## 实训目的

- 掌握 `74LS90` 二-五-十进制计数器的 8421 BCD 接法及异步级联进位原理，自主搭建 `00 ~ 99` 二位十进制计数器。
- 掌握 `CD4511` BCD-七段锁存/译码/驱动器与共阴极七段数码管的配合工作原理，通过真实仿真实时观测数码管显示与清零控制。
- 用示波器实测输入时钟 `U1_CP0` 与个位进位输出 `U1_Q3` 的频率关系，验证十分频级联规律。

## 实训原理

原理图见“原理图”标签页（点击插孔可与 3D 台面双向高亮联动）。

1. **8421 BCD 十进制计数单元（`74LS90`）**：
   芯片内部由独立的模 2 触发器（输入 `CP0`、输出 `Q0`）与异步模 5 计数器（输入 `CP1`、输出 `Q1~Q3`）组成，均为**下降沿触发**。将 `Q0` 外接至 `CP1`，时钟输入 `CP0`，清零端 `R0` 置低电平，即构成 8421 BCD 十进制计数器（`0000 ~ 1001` 循环）：

   $$f_{Q3} = \frac{f_{\text{CLK}}}{10}$$

2. **两级十进制级联（`00 ~ 99`）**：
   个位 `U1` 计到 `9`（`Q3 Q2 Q1 Q0 = 1001`）后，下一个时钟下降沿使个位回到 `0`（`0000`），此时 `U1_Q3` 恰好产生一个 `1 → 0` 下降沿。将 `U1_Q3` 接至十位 `U2_CP0`，即可在 `09 → 10`、`19 → 20`、…、`99 → 00` 瞬间触发十位加 1。

3. **BCD 译码与共阴数码管显示（`CD4511`）**：
   两片 `CD4511` 接收各自 `74LS90` 的四位 BCD 码 `D C B A`，按真实真值表驱动共阴极七段数码管 `a ~ g` 七路限流支路（`330 Ω` + 共阴极负载）。挂箱数码管直接由 ngspice 计算得到的 14 路真实段电压点亮，不经脚本硬编码数字。

## 实训步骤

1. **初始核查**：台面保持断电，确认挂箱脉冲频率处于 `2 Hz`、清零开关 `R0` 置于 `计数 (0)`。
2. **搭建级联计数与译码电路**：断电连接电源 `ins-dc-power.V5P → dig1.VCC`、`ins-dc-power.V5N → dig1.GND`；连接时钟 `CLK_OUT → U1_CP0` 与清零线 `RST_OUT → U1_R0`、`U1_R0 → U2_R0`；按 8421 接法连接 `U1_Q0 → U1_CP1`、`U2_Q0 → U2_CP1` 与进位线 `U1_Q3 → U2_CP0`；将 `U1_Q0~Q3` 分别接 `D1_A~D1_D`、`U2_Q0~Q3` 分别接 `D2_A~D2_D`。点击“检查接线”确认通过。
3. **核查供电电压**：接入固定直流电压表（20 V 档）测 `VCC`–`GND`，上电确认约 `5.0 V` 并记录 `vcc`。
4. **观测实时级联计数**：在“模块控件”或台面将脉冲频率切换为 `5 Hz` 或 `10 Hz`，观察挂箱顶部十位/个位共阴数码管从 `00` 连续递增并顺利完成 `09 → 10` 十位进位。
5. **示波器验证十分频**：断电放置双通道示波器，接 `CH1 → U1_CP0`、`CH2 → U1_Q3`、`GND → GND`，保持 `10 Hz` 脉冲、时基 `0.5 s/div`，上电待捕获至少 2 个完整周期后记录 `f_clk` 与 `f_carry`，验证 `f_clk / f_carry ≈ 10`。
6. **验证异步清零**：运行中拨动清零开关 `R0` 至 `清零 (1)`，确认两位数码管立即归零显示 `00`；拨回 `计数 (0)` 恢复递增计数。断电核对数据表并完成思考题。

## 注意事项

- **必须连接 `+5 V` 供电**：未连接 `VCC`/`GND` 时，`74LS90` 与 `CD4511` 均处于断电关闭状态，不会计数也不会点亮数码管。
- **严禁将电源反接或短接**：移动导线或增删示波器前务必先断电；`CLK_RATE` 频率旋钮与 `RST_SW` 清零开关支持运行中连续调节。
- **区分个位与十位进位端**：只有 `U1_Q3` 在 `9 → 0` 时输出下降沿，若误接 `U1_Q0` 到 `U2_CP0` 会变成二分频而非十分频。
- **示波器频率测量窗口**：`10 Hz` 脉冲经十分频后 `U1_Q3` 为 `1 Hz`（周期 `1 s`），测量频率需选用 `0.5 s/div` 及以上时基并等待至少 3 个上升沿（≥2 个完整周期）。

2. 两片 74LS90 级联实现 00~99 计数时，为什么把个位 Q3（而非 Q0）接到十位 CP0？进位发生在个位哪个状态跳变瞬间？
