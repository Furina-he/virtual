- **做法**：
  1. `src/domain/task/charts.ts` 与 `report.ts` 提供从 `Project.charts` + `TaskState.tables` 提取有效点的纯函数以及结构化报告数据组装。
  2. 底栏“曲线”标签页接入 shadcn `Chart`（Recharts）渲染折线/散点曲线；顶栏“导出报告”经主进程 `webContents.printToPDF` 生成含数据表、曲线、示波器截图（`screenshots`）与思考题答案（`answers`）的 PDF。
- **验收**：
  - 单元：`src/domain/task/charts-report.test.ts`（带 `TSK-04`、`TSK-05`、`TSK-06`、`T1.6`）覆盖曲线点提取、空值过滤与报告模型拼装。
  - 端到端：`tests/e2e/charts-report.spec.ts` 覆盖记录数据后生成曲线及导出非空 PDF 文件（含示波器截图与思考题答案）。

#### T1.7 存档、自动存档、崩溃恢复 ☐

- **目标**：实现项目进度的本地手动保存/读取、接线与记录变更后 2 s 防抖自动存档（`.autosave` 原子写）以及异常退出重启后的崩溃恢复提示（WIR-05、NFR-04、技术设计 §9）。
- **做法**：
  1. 主进程 `src/main/storage.ts` 实现 `SaveFile`（`userData/saves/<projectId>.json` 与 `.autosave`）先写临时文件再 `rename` 的原子读写 IPC，恢复后一律保持断电（`powered: false`）。
  2. 渲染端监听接线、仪表、数据表、思考题和排故记录变更做 2 s 防抖自动存档；重新进入项目或强杀重启后检测未正常关闭的 `.autosave` 并支持一键恢复。
