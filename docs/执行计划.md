## 使用方式

本文是唯一的进度来源：当前状态、优先级、任务和待决策事项都只在这里维护，不另建状态页、交接或总结文档。

- 直接按"近期优先级"开工，不需要领取、回执或评审流程。做完一项就在对应任务下勾选状态，写**不超过 3 行**结果：日期、提交、验证命令，有录屏或日志时补证据路径。
- 当前成绩只写在"当前状态"的回归基线；任务下只记完成时的提交和证据，不复述最新成绩。过程细节和中间失败轮次追加到 [开发进度日志](archive/开发进度日志.md)。
- 已完成的事项移出"近期优先级"和"待决策"，结论留在对应任务或技术设计里。
- 结果回填和对应代码放在同一个提交，不单独提交"记录成绩"的文档改动。
- README、技术设计和接口文档不写进度或成绩，只链接本文"当前状态"。
- 任务写明目标、做法和验收标准，验收标准全部满足才算完成；能自动化的都写成测试，并在验收里写出测试文件。新写的测试标题带 PRD 需求编号或任务编号（如 `SIM-11`、`T1.4`），便于从验收反查测试。部分完成就保持 ◐，并写清还差什么。
- 需求或设计要改时，先改 PRD 或技术设计再写代码。需要拍板的事写进"待决策"，不在代码里绕过。
- 成绩写明日期和提交；没重跑的旧成绩不能当作新成绩。
- 计划粒度：M0 为完整任务；M1 为任务级；M2 为批次级。M1 任务开工前先细化成 M0 的格式（目标、做法、验收），并依据 M0 实测重估工期。
- 3D 模型、原型资料、学习素材全部由我方自行获取，不依赖甲方提供。

### T0.16 3D 实训台可操作性改造 ◐
- **依赖** T0.8、T0.9　**参考** 技术设计 §10.3；PRD BEN-06/07/08、WIR-01/04/08、15.2、15.5
- **起因**（2026-10-31 实测现有构建，1920×1080、DPR 1.25）：
  - 默认视角下挂箱插孔间距 7.2 px，1366×768 下 4.7 px；WCAG 2.5.8 要求可点目标 ≥24 px。
  - 空白处左键拖动即旋转；导线未完成时相机锁死；滚轮朝轨道中心缩放。
  - 只有三个预设，没有聚焦；3D 控件没有悬停或光标反馈。
  - 渲染：没开各向异性过滤，ACES 色调映射把面板压灰，接触阴影在地面而不是台面。
  - 市场调研：LVSIM-EMS、Multisim 和国内招标的做法一致，都是左键操作、滚轮缩放、右键旋转，并能聚焦接线端子。
- **P0（不加依赖、不改资产）**：
  1. 键位：左键只用于操作（点插孔、调控件），拖空白处为平移；右键拖动为受限旋转（水平方向 ±45°，俯仰受限，目标点限制在台子包围盒内）；中键平移；滚轮朝光标缩放。
  2. 视距：分全景和特写两级。双击设备进入正对特写；Esc 退一级，Home 回全景；新增模块、仪表预设（BEN-06）。默认视角保持场景相机不收紧，因为台面安装位要在全景里可见（实施时调整）。
  3. 接线：以点一下开始、再点一下完成为主，按住拖放保留。接线过程中缩放、平移、旋转和双击聚焦照常可用。插孔按屏幕距离 24 px 吸附最近的可见插孔；导线点选范围为屏幕 8 px。设备插孔屏幕间距 <14 px 时单击该设备先进入特写（实施时补充，解决全景误接）。
  4. 反馈：悬停在插孔、控件或导线上时光标变为手形，控件同时高亮。3D 旋钮支持滚轮逐档调节，悬停时滚轮调旋钮、不缩放场景。
  5. 渲染：面板贴图各向异性过滤取硬件上限；色调映射改为 NeutralToneMapping；接触阴影移到台面高度。
- **P1**：
  - 特写时用 `<Html>` 叠加 12–13 px 屏幕标签，只显示光标附近的；丝印适度放大，内容和位置不变（BEN-02 已由用户批准）；丝印里的 "ohm" 统一写成 Ω。
  - 导线右键菜单：删除、改色、调垂度。
  - 单击仪表时镜头聚焦，并高亮对应的 2D 面板。
  - 引导模式用虚线显示参考接线。
  - 调整默认分栏扩大视口，加"专注台面"开关；首次进入给三步提示。
- **验收**：
  - 1366×768 和 1920×1080 下，插孔有效拾取范围 ≥24 CSS px，由 E2E 测量。
  - 从全景到任意设备特写只需一步；跨设备接一根线不用退回全景；任何情况下左键都不旋转视角。
  - 现有 E2E（接线、仪表拖放、SD-22、场景性能）按新键位更新后通过；NFR-02 帧率门槛不变。
  - `assets/generated/` 下的旧截图换成改版后的截图。
  - P1 完成后人工对比新手接 DG-05 的 9 根线：用时和误点次数。
- **结果**：P0 完成（2026-11-01，`3c2c9d2`），新增 E2E 覆盖单击特写、24 px 吸附、待接线时缩放、左键不旋转、右键 ±45°、Esc/Home；P1 完成（2026-11-21，`186ca49`），丝印 ohm→Ω 只重建四个非 SD-22 资产，SD-22 锁定字节未动，`assets/generated/` 工作台截图已替换。两项均纳入 2026-11-22 全量回归（见 [当前状态](#当前状态)）；中间轮次失败与场景性能复测记录在 [开发进度日志](archive/开发进度日志.md)。
