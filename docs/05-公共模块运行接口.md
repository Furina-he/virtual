# 公共模块运行接口

版本：T0.15/B 公共接口草案，2026-10-29。本会话负责公共实现与 MD-03；SD-22 的项目内容、555 板和专用测试由独立 `codex/sd22` Worktree 负责。本文件及公共代码单独提交，两个分支引入相同接口后再统一合并资产元数据。

## 1. 模块声明

```ts
ModuleControl = {
  id: string; param: string; kind: 'pot' | 'switch' | 'rotary' | 'resistorBox'
  label?: string; unit: string; default: number
  range?: [number, number]; step?: number
  steps?: number[]; stepLabels?: string[]
  targets?: { element: string; scale?: number; offset?: number; min?: number; values?: number[] }[]
}
Module.simulation?: {
  analysis: 'tran'; maxStep: number; pacing?: 'realtime' | 'window'
}
SpeakerIndicator = {
  id: string; kind: 'speaker'; between: [JackId, JackId]
  audio: { fullScale: number }
}
```

- 状态仍是 `controlValues['<实例>.<控件>']`，数值按内容范围和档位校验；`param` 必须对应子电路 `params:` 中的参数。`stepLabels` 与 `steps` 一一对应，非扬声器指示器仍兼容已有 `probe` 声明。
- 拼装器生成 `.param p_<安全实例>_<param>=值`，并通过子电路参数引用。电位器用参数电阻，开关用有限开/关电阻或受控开关，结构保持不变。不能通过开关动作增删元件。
- `simulation` 显式要求连续瞬态，`maxStep` 为最大采样步长；未声明仍沿用已有仪表驱动分析。声明但未指定节奏时默认实时。纯放大器可显式 `window`；低频状态模块必须声明 `realtime`。
- 扬声器 `between` 只接受本模块实际插孔，编译为固定探针 `indicator:<实例>:<指示器>`，通过节点映射测两端电压；不执行任意 probe 字符串。`audio.fullScale` 是电压到音频满幅的比例，生产输出统一复用已选定的 synth `SimAudioOutput`。

## 2. 运行中改参数

```ts
{ type: 'load', ..., parameterTargets?: { param: string; elements: string[] }[] }
{ type: 'alter', requestId?: string, changes: { param: string; value: number; targets?: { element: string; value: number }[] }[] }
{ type: 'altered', requestId?: string, simTime: number, changes: { param: string; value: number; targets?: { element: string; value: number }[] }[] }
```

- 只有声明的模块参数值改变，并且接线、模块/仪表、故障、预检、探针、分析、步长与节奏都相同，才发送 `alter`。其它变化仍走完整载入，不将重启宣称为连续改参。
- 连续瞬态的控件必须声明 `targets`：每项是本模块的实际电阻元件名，线性换算 `max(min, value*scale+offset)`，或 `values` 按 `steps` 索引映射阻值。映射仅支持有限正电阻，不执行任意公式或猜测网表。拼装计划把它展开为 `r.x<安全实例>.<元件>`，载入声明允许的参数/元件集合，后续 `alter` 同时发送逻辑参数和已求值电阻目标。仿真核只更新载入时声明的目标，避免任意元件改写。
- ngspice 在 50 ms 片间隙直接 `alter` 已展开的电阻值，连续瞬态不执行 `reset`，之后 `bg_resume`；逻辑 `.param` 仅同步用于保存和重启恢复。直流工作点与既有未声明目标的旧接口保留原参数处理，但不声称其可保持被改支路储能状态。成功后回传 `altered`。IPC 返回只表示接收，不是参数生效。运行端使用请求序号确认，参数待生效期间禁止记录旧值，确认后还须有生效时刻以后的采样/读数。
- 保留会话序号、探针 ID、RingBuffer、RMS 与扬声器订阅；快速连续操作不能由旧确认恢复新参数的记录权限。参数失败必须可见并停止错误作业，不能仅写日志再继续假装成功。
- 追加的真实 RC 测试已否定“`alterparam + reset` 对被改支路也保留电容状态”：时间和块序号继续，但改支路的解析误差约 1.79 V，不能放宽原 0.02 V 阈值。采用直接电阻更新后重新验证被改支路 RC 的分段解析解、源绝对相位、块序号/时间和参数开关；不承诺任意模型参数、改变电容值或拓扑都可连续修改。
- 当前参数和节奏纳入重启恢复；仿真进程重启是新的采样会话，渲染端清理旧数据并恢复最新内容设置。
- 公共验证：被改支路 RC/绝对正弦相位、子电路电阻开关、工作点确认顺序和目标白名单的真实 ngspice 测试 4/4 通过；工作台已有直流挂箱开关的真实 E2E 1/1 通过且会话载入次数不增加。共享锁日志为 `build/module-parameters-golden-verified.log`、`build/codex-public-module-e2e.log`。仍须 MD-03 实际 RW/KCE 长流程验证，不能用这些公共测试替代项目验收。

## 3. 节奏与声音生命周期

- 任一模块要求实时，或存在扬声器，实时节奏优先于示波器窗口；波形仍从同一真实仿真缓冲读取。长时基不得加速低频事件或音频调制。
- 步长同时满足模块、信号周期、示波器和声音采样限制。模块/声音的硬上限不能被示波器每屏预算反向放宽。
- 主工作台只有一个声音生产者，弹出仪表窗口不重复发声。声音使用自己的 AudioContext，不破坏万用表通断蜂鸣。
- 创建声音实例的每次异步等待后都核对作业/资源代号。断电、错误、重置、项目切换、重载和销毁时，先解除逐块订阅，再静音/停止并关闭捕获的旧 context；晚到的创建结果立即停止。真正的参数 alter 不重建音色追踪器。
- 新会话不能把时间归零后的数据喂给旧追踪器。不得增加预缓冲或放宽欠载阈值掩盖性能问题；既有 PCM A 历史观察项仍保留。

## 4. 示波器记录与教学计算

- 波形测量点使用 `quantity: 'mean' | 'vpp' | 'min' | 'max' | 'frequency' | 'period'`，默认 `vpp`。记录只从实际接线且有效的示波器通道取最新真实测量；GND 耦合、未接参考地、未就绪或旧参数数据不能作为测量证据。
- `mean/min/max` 使用 DC 耦合；反接时均值变号，极值交换并变号；Vpp/频率/周期保持非负。数值单位由测量量决定，不解析显示文本或注入理论值。
- 同一示波器的两个有效 DC 通道可作为 `CH1-CH2` 或 `CH2-CH1` 的同步差分记录来源；必须具有一致的采样步长、结束时刻和共同参考地，先逐点相减再测量，不把两次标量极值相减冒充时域差值。该能力仅用于记录实测差分，不宣称完成 INS-11 整套增强功能。测 VCE 时保持示波器地线接电路 GND，CH1 接 C、CH2 接 E；禁止为了省差分把实际接地地夹接 E 而短接发射极电阻。
- 数据列可用 `captureSteps?: string[]` 限制当前阶段记录，防止空载和带载共用测量插孔时同时覆盖两个记录。步骤可用 `dataTable?: string` 指定关联表，引用由 schema 校验。
- 已有 `computed` 字段只允许同一行数值列、数值常量、括号与 `+ - * /` 的有限算式，不使用 `eval`、JS 函数或任意属性访问；缺测量、零分母或非法运算产生未完成值和明确提示。公式只处理记录，不驱动仿真。

## 5. Worktree 重测试互斥

两个 Worktree 共享 Git common directory。全量测试、真实仿真金标准、Electron E2E、音频、性能和资产构建通过以下入口占用同一个验证锁：

```powershell
node tools/run-exclusive.ts test
node tools/run-exclusive.ts test:golden tests/golden/<本分支测试>.test.ts
node tools/run-exclusive.ts e2e
node tools/run-exclusive.ts e2e:only tests/e2e/<本分支测试>.spec.ts
node tools/run-exclusive.ts assets:build
```

锁文件位于 `<git-common-dir>/codex-coordination/heavy-test.lock`，记录 PID、任务、工作区和启动时间；已有占用时返回 75，并显示占用者，不自动删除。另一分支未引入脚本前不得同时直接跑重测试。正常退出释放自己持有的锁；异常终止留下的锁须确认原进程与子测试均结束后人工处理。类型、lint 和纯轻量单元测试可并行；资产目录的 manifest/许可证等生成输出最终统一合并与校验，不能以覆盖一方文件代替合并。
