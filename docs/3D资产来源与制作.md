## 2. 制作与复现

使用项目已有锁定的 Node/TypeScript、Three.js 与浏览器能力。不另装 CAD 软件，不通过未锁定的 `npx` 临时安装压缩器，不引入新的渲染库。

```bash
# Only needed to restore pinned source files; this step uses the network.
pnpm assets:fetch

# Local asset production and checks; no network fetches.
pnpm assets:build
pnpm assets:lint
pnpm content:lint

# Application compilation, separate from asset generation.
pnpm build:app

# Read-only visual QA of the generated component/tool GLBs.
node tools/assets/gallery.ts
```

`assets:fetch` 对应 `tools/assets/fetch-sources.ts`，按 `assets/sources.json` 中固定的原站 URL、字节数和 MD5 获取或核对资源。已入库来源文件无需每次重复下载。它不是应用启动逻辑，也不在离线 `assets:build` 中隐式执行。

`assets:build` 的实际实现是 Node 启动仅绑定 `127.0.0.1` 的临时 HTTP 服务，去掉工具 TS 的类型后通过本地 import map 提供已锁定的 Three.js；Playwright 启动**隐藏的 Electron 窗口**执行 `export-browser.ts`。浏览器内完成几何组装/外部 GLB 适配、字体等待、Canvas WebP 编码和 GLTFExporter 导出，仅回写已声明的管线输出。它不是 electron-vite 构建，也不访问网上模型服务。`pnpm build:app` 才是单独的 electron-vite 应用编译步骤。

面板文字使用项目已有的 Noto Sans SC 字体子集；`panel.svg` 内嵌字体，Canvas 在本地字体加载完成后绘制文字，避免 SVG 图像尚未完成字体解析时生成乱码。GLB 内嵌 WebP，模块/仪表/实训台另保留同源 `panel.svg`、`panel.webp`。元器件和组合钳无贴图，使用材质/顶点颜色。

### 数据契约

- `content/modules/mod-dc-circuit/module.json` 的 `jacks` 是插孔契约；现有 `module.cir` 是电路源。构建器只生成视觉资产，不覆盖 `.cir`，不从面板连线猜电路。
- 制作坐标为 mm，面板左上角原点，x 向右/y 向下。导出变为米、底部安装面中心原点、+Y 向上、正面 +Z；插孔朝向随面板变换。
- `JACK_<id>` 与已存在的模块/仪表 JSON 一一对应；DG-05 的 24 个插孔和 `SW_K1`、`SW_K2`、`SW_K3` 保持已有 ID。模块 `.subckt` 端口顺序与 `module.json.jacks` 一致，不能只比较数量。示波器/信号发生器尚无 `instrument.json`，本批只核对其布局锚点，不编造仿真模板；内容与逻辑在 T0.12 补齐后再校验。
- 直流电压表、电流表、控制屏电源按 Q-A 固定安装，分别使用控制屏的 `SLOT_INS_DCV`、`SLOT_INS_DCA`、`SLOT_INS_DCPOWER`；内部接线不建模。仪表柜只放台式仪表，所有外部测量线仍由学员连接。
- `SCREEN_` 保留独立屏幕面，`KNOB_`/`SW_` 保留控制件，`LED_`/`LAMP_` 保留可驱动发光节点。静态表头不显示冒充实时结果的数字；读数、波形及控件逻辑在 T0.11/12 绑定。
- 模块/仪表合批保留交互锚点和可动件。当前 10 个元器件按 `STATIC_paint`、`STATIC_metal` 合批，仅供外观认知；尚未提供逐引脚 `Pin_n`、`Body` 等教学拆解节点或具体型号引脚映射。T1.9 需按教学目标补齐，不能将通用 TO-92、DIP-8 外形当作 9013、NE555 的引脚说明。

### 已取得的证据与当前遗留

- 19 个 GLB 已生成并通过静态资产检查；GLB 索引类型、字节范围、顶点越界、端口顺序、固定仪表位置、硬面数预算、输出路径与来源匹配均增加了反例检查。最终 `pnpm test` 172/172 通过（22 个测试文件，68.39 s，包含当前配置纳入的仿真金标准）；`pnpm lint` 检查 116 个文件通过，`pnpm typecheck`、`pnpm content:lint` 均通过，`pnpm assets:lint` 对 19 个 GLB 报告 0 问题。最终串行 `pnpm e2e` 12/12 通过，证据为 `build/asset-e2e-verification.log`。
- 工作台实际加载 8 个模型（实训台 + 挂箱 + 6 台仪表），自动识别 92 个交互锚点，其中 42 个插孔。静态预览合计 21,990 三角面、63 个**几何绘制批次**；该数字不包含阴影/HDRI 处理等额外 GPU 工作，不等于完整场景 Draw Calls 或 FPS 验收。
- 工作台截图 `assets/generated/bench-preview.png`、`assets/generated/bench-preview-expanded.png` 均为 1366×768；面板中文、插孔、固定表位置与常规/展开状态已目检。`assets/generated/component-gallery.png` 独立显示 10 个元器件和组合钳，确认实际网格可见、名称不冒充具体型号或认证。
