## 2. 默认关闭的公共诊断入口

`SimSession` 第四个可选构造参数为本地 `onProfile(profile)`。未提供时不计算电路哈希或时段统计，不注册逐点 SendData、不增加 IPC/React 高频状态。每片只产生一个聚合记录，包括：

- `loadId/circuitHash/sliceSeq/firstSeq/lastSeq` 与 `simFrom/simTo`；
- 原始/输出点数、探针数、读取次数、唯一向量、读出/输出字节、trim 命令数；
- 控制命令、bg 调用、bg 停止回调到达、回调排队、读取、差分/Chunker、emit、trim、命令释放和前置 pacing 等时段。

`bgObserved` 包含原生求解和回调交接，不叫纯 solve；`afterSlice` 包含其读取/转换/发送/trim 子项，不能再与子项相加当作不重叠总时长。诊断消费者抛错不会改变正常仿真状态。

`tools/sim-profile.ts` 仅接受真实 transient `load` JSON，要求父进程持有共享锁、拒绝覆盖已有证据，最多每 100 ms 查询一次原生 rusage。Node 22 的开发期执行须临时启用类型转换，并恢复环境：

```powershell
$previous = $env:NODE_OPTIONS
try {
  $env:NODE_OPTIONS = '--experimental-transform-types'
  node tools/run-exclusive.ts script tools/sim-profile.ts build/t015-integration/ambulance-load.json --seconds=2 --output=build/t015-integration/new-profile.json
} finally {
  $env:NODE_OPTIONS = $previous
}
```

可选 `--klu`、`--threads=N`、`--noref` 都只是显式诊断变量，不改变生产默认。不得把工具的有限值/无断采验证误写成实际音频性能通过。4 项无 DLL 回归通过，见 `build/t015-integration/profile-unit.log`。

## 3. 原生分段基线

短墙钟预算后等待最后一个实际片完成，因此 `approximateRatioIncludingTail` 会包含预算外末片；该比值不是正式实时验收数据。以下累积时段都包含该末片：

| 真实输入 | 预算墙钟 | 实际末片时间 | bgObserved | afterSlice（含子项） | read | 差分/Chunker | emit | trim |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 救护车 2 µs | 2.015 s | 0.400002 s | 2102.98 ms | 46.89 ms | 2.35 ms | 24.12 ms | 14.78 ms | 5.12 ms |
| 缓冲消防车 2 µs | 2.000 s | 0.300001 s | 1976.87 ms | 40.26 ms | 1.73 ms | 19.31 ms | 14.36 ms | 4.35 ms |
| MD Ro 带载 0.2 µs | 3.006 s | 0.200000 s | 3000.53 ms | 113.32 ms | 6.68 ms | 64.29 ms | 25.29 ms | 16.61 ms |

三个输入均 0 缺块/断采、0 非有限值。证据为 `*-native-baseline.json`（消防车文件名为 `fire-native-baseline.json`）与 `native-profile-baseline.log`、`md03-native-profile.log`。

SD 原生接受约 20.4 万/15.3 万步，拒步均 7 次，Newton 迭代约为每接受步两次；MD 接受约 101.2 万步，拒步 1 次。不是大量拒步才造成这些慢速片。SD 原生 load 约占 transient analysis elapsed time 的 53–56%；原生 factor/solve/trunc 和未独立分账的 XSPICE/输出/控制等也占时间。

当前官方 OpenMP 构建的 `IFseconds` 使用 `omp_get_wtime()`，上述 rusage 是原生段 elapsed time，不是独立 CPU 计数。独立 SD Electron 证据中的约 8% 整机归一 CPU（12 逻辑核）只旁证进程接近一个逻辑核占用，不当作物理单核或目标机认证。
