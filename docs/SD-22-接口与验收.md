# SD-22 公共接口与验收边界

现行基线：2026-10-30，联合整合工作区。**内容/模型已整合，应用验收未完成。** 最新结果与下一阶段闸门只在 [当前状态](执行计划.md#当前状态) 维护，本文保留现行电气/接口和完成条件；旧分支、建议字段、逐轮回归及录屏说明见 [SD-22 开发记录](archive/SD-22开发记录.md)。

## 电气与器材边界

- 原型依据 [原型选型说明](原型选型说明.md) §5.4；原 264×184 mm、36 插孔 ID/顺序/坐标和全部 RC 参数不变。旧音频原型 fixture 参数不同，不得替换正式板参数或反向覆盖旧测试。
- 正式供电 5 V：RA1=10 kΩ、RB1=150 kΩ、C1=4.7 µF；RA2=RB2=10 kΩ、C2=47 nF；C3=C4=10 nF、R5=10 kΩ、C5=100 µF；扬声器 8 Ω/0.5 W。
- 用户已批准独立 TLV9001IDBVR 四孔跟随器 `follower1/mod-voltage-follower`，同源 5 V/GND、负反馈与 100 nF 去耦。它是独立命名的估计模型，不冒充厂商拟合，也不篡改 NE555 三只 5 kΩ 分压。
- 消防车使用 `T1_TH -> follower1.IN`、`follower1.OUT -> R5_1`；救护车使用 `T1_OUT -> R5_1`，调制来源互斥。原 TH 直连停振证据保留，不能声称原型原接法正常。
- C1 上的真实示波器负载为 1 MΩ/20 pF，并会改变低频；裸板与接表理论分开，不将接表结果改填成裸板值。科学依据见 [SD-22 电路审核](SD-22-电路审核.md) 与 [缓冲修订](高输入阻抗缓冲修订.md)。

## 公共契约与内容绑定

公共实现以 [公共模块运行接口](公共模块运行接口.md) 为准，不能从归档建议复制旧字段。

- `Module.simulation={analysis:'tran',maxStep:2e-6,pacing:'realtime'}`；实际步长同时满足模块、仪表与声音约束，不能另起加速仿真流。
- 扬声器声明为 `{id:'LS1',kind:'speaker',between:['SPK_P','SPK_N'],audio:{fullScale:5}}`，不解析任意 `probe` 表达式。`indicator:timer1:LS1` 消费实际差分采样，主工作台只有一个声音生产者。
- 每次运行以真实 `load/requestId -> loaded/requestId` 确认关联；声音准备/激活、断电、重置、换项目、错误及晚到资源释放复用公共生命周期，弹出仪表窗口不重复发声。
- 项目包含 17 步、6 张空表、10 题；每步声明完整 `referenceNets`，波形点声明 `quantity`，周期点 `minCycles=2`；`captureSteps` 隔离记录阶段。手填、连通或有声音不等同于测量完成。
- `expect` 与 `expects` 对同一实测证据做 AND 门禁。CV mean/min/max 使用同一完整 `windowSec=0.2` 平台窗；非周期 min/max 不强求周期，但实际覆盖和每项原范围都要满足。真实混合值可记录与提示，不能据此推进。
- 长窗保持 16 s/2048 槽、原始 RingBuffer 262144 点/1 MiB、记录 scratch 65536 点；频率逐原始样本判沿，长屏显示真实 min/max 包络。不得扩容、裁启动或把 0.2 s 改为 raw 短窗的约 0.131 s。

## 验收条件

| 出口 | 必须满足 |
|------|----------|
| 电路与负载 | 正式两模式、原板停振回归、批准缓冲及真实表负载金标准通过；保留原物理误差和模型边界 |
| 实时 | 同一真实 2 µs 流，两模式原 8 s 墙钟 `realtimeRatio > 0.95`；慢速追加观测不能覆盖失败 |
| 完整流程 | 原 15 s 周期门禁与逐步实测成立；17 步/6 表真实记录、两模式完整接线/上电/测量/记录录屏 |
| CV 平台 | 实际应用到达平台步骤；同一完整 0.2 s 覆盖，mean/min/max 各满足原范围，无旧平台污染 |
| 声音与生命周期 | 本应用自身视频/真实音轨、唯一生产者、断电/断线/重置/切项目资源释放；自动解码不能当人工试听 |
| 联合回归 | DG-05/MD-03/SD-22 的完整 E2E、单元/真实金标准、内容/资产/许可证联合校验均通过，不用定向成绩替代 |

项目验收与目标机、正式器件参数/教学审核分开描述；未通过上述出口不能关闭 SD-22/T0.15。
