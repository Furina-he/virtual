# 内容完成标准与模板指南

| 项 | 内容 |
|----|------|
| 版本 | V0.1（2026-11-24，T1.10 固化 M2 内容量产标准、模板与 `content:lint` 静态门禁） |
| 依据 | [PRD](../电工电子技术虚拟仿真教学软件PRD.md)（NFR-07、TSK-01~08、LRN-01~08、§7~§8）、[技术设计](技术设计.md) §3、[公共模块运行接口](公共模块运行接口.md) |
| 定位 | 供内容编写线、仿真/资产线独立产出 61 个实训项目、90 个元器件、38 个集成电路、仪表工具及挂箱模块的唯一内容标准与模板手册；进度只看 [执行计划](执行计划.md) |

按 ADR-004 与 NFR-07，项目、挂箱模块与学习资源全部由 `content/` 下的配置、Markdown 与本地资产驱动，**新增或修改内容不得在公共代码中按项目编号或器件 ID 分支**。所有标准模板存放在 `tools/templates/`（不进运行时安装包），内容线可直接复制或使用 `pnpm content:new` 生成脚手架，提交前必须通过 `pnpm content:lint` 静态门禁。

## 1. 实训项目完成标准（61 个项目，PRD §7）

每个正式教学项目位于 `content/projects/<ID>/`（目录名与 `project.json` 中 `id` 严格一致，格式为 `DG-01`~`20`、`MD-01`~`19`、`SD-01`~`22`），必须交付以下三类核心文件并满足全部验收门槛：

| 文件 | 必选性 | 门禁要求 |
|------|--------|----------|
| `project.json` | 必选 | 通过 `src/shared/schema/project.ts` 校验与 `pnpm content:lint` 跨文件引用检查 |
| `guide.md` | 必选 | 通过 `pnpm content:lint` 六项二级标题顺序、正文非空与离线媒体检查 |
| `schematic.svg` | 正式项目必选 | 离线有效 SVG（零外网 `http(s)://` 引用），标注插孔供 `SchematicViewer` 双向高亮 |

> **功能验证夹具边界**：尚未配齐正式挂箱/教学内容的开发验证场景（如 `DG-01`、`DG-19`）必须在 `project.json` 显式声明 `validation: { purpose, limitations }`，不得冒充正式交付项目；即便带 `validation`，其 `guide.md` 仍须满足六项标准结构，已附带的 `schematic.svg` 仍受离线有效性校验。

### 1.1 `project.json` 编写规范

- **分组命名**：严格对齐 PRD §7 与 Q5——电工基础用 `直流电路` / `交流电路` / `磁路与变压器` / `暂态电路`；模拟电子按 `basic` / `integrated` 归组；数字电子综合组固定命名为 `综合性应用仿真实训项目`。
- **模块与仪表**：
  - `modules` 声明启动时自动挂载的挂箱/实验板实例（`instanceId`、`moduleId`、`slot`），`slot` 必须为实训台有效模块插槽（如 `SLOT_BOX_L1`、`SLOT_BOX_L2`）。
  - `allowedInstruments` **只能放 `mounting: "desktop"` 的台式仪表**（如 `ins-multimeter`、`ins-oscilloscope`、`ins-func-gen`、`ins-power-meter`、`ins-ac-millivoltmeter`、`ins-galvanometer`）；固定在控制屏上的仪表（`mounting: "fixed"`）自动在场，禁止列入 `allowedInstruments`。
- **参考拓扑与测量点**：
  - `reference.nets` 描述电路本体参考等电位网络，不包含测量仪表表线；每个插孔在同组拓扑中至多属于一个网络。
  - 若分阶段改线（如空载/带载、救护车/消防车切换），在对应步骤显式声明 `steps[i].referenceNets` 完整替换当步网络。
  - `reference.measurePoints` 须声明准确 `kind` / `mode`（防止交直流错档写入）；波形测量点按需声明 `quantity`、`minCycles`（周期量 ≥2）与 `windowSec`（有界长窗）。
- **步骤、数据表与曲线**：
  - `steps` 覆盖完整操作顺序，按需配置 `checkWiring`、`measurePoints`、`expect` / `expects`、`dataTable`、`recordTable`。
  - `dataTables` 绑定 `measurePoint`（支持快捷记录）、`captureSteps`（防跨阶段覆盖）、`computed`（纯四则运算公式列，禁止手填或预填理论值）与 `sanity`（明显不合理读数提示）。
  - 名称含“测绘 / 绘制 / 特性”的项目必须配置 `charts`（`line` 或 `scatter`），确保底栏“曲线”与 PDF 报告可出图（TSK-04）。
- **故障点与思考题**：
  - 排故项目在 `faults` 中声明四类故障（`open`、`short`、`drift`、`dead`），`target` 格式为 `<instanceId>.<元件名>`；`pnpm content:lint` 会直接尝试对模块 `.cir` 执行 `injectFault`，确保每个故障都可无错注入。
  - `questions` 与 `guide.md` 思考题对应，供“思考题作答”输入框与 PDF 报告汇总使用。

### 1.2 `guide.md` 六项强制结构（TSK-01 / `content:lint` 门禁）

`guide.md` 必须按下列顺序包含 6 个二级标题（`##`），**不可缺项、不可重复、不可降级为 `###`、不可放在代码块中冒充、每节须有实质正文，且严禁嵌入外网图片/音视频 URL（NFR-09）**：

1. `## 实训目的` — 明确本项目的教学目标与验证物理量（如有估计模型边界须诚实说明）。
2. `## 实训原理` — 电路分析、关键公式（支持 KaTeX `$...$` / `$$...$$`）与误差/加载机理；须注明公式仅作原理校核，不向仪表或表格预填理论值。
3. `## 器材清单` — 列出挂箱/实验板实例、固定仪表、仪表柜可选仪表与关键器件参数（可用 GFM 表格）。
4. `## 实训步骤` — 与 `project.json` 中 `steps` 一一对应，说明接线、档位选择、上电测量、记录与断电改线顺序。
5. `## 注意事项` — 安全联锁规范（先断电再改线、禁电流档并联、示波器共地禁忌等）与模型/量程注意事项。
6. `## 思考题` — 编号列表形式列出本项目的分析与排故思考题。

### 1.3 `schematic.svg` 交互原理图规范（TSK-02 / T1.9B）

- 采用本地代码原生 SVG（`xmlns="http://www.w3.org/2000/svg"`、`viewBox`、`<title>`、`<desc>`），字体统一使用本地 `Noto Sans SC Variable`，禁止任何 `href="http..."`、`src="http..."` 或 `url(http...)`。
- 为需要与 3D 实训台双向高亮及原理图两点直连的插孔圆点标注 `data-jack="<instanceId>.<jackId>"`（推荐同时保留 `id="JACK_<jackId>"`），`SchematicViewer` 将自动识别并启用悬停联动与两点直连。

### 1.4 单个项目完成验收门槛（M2 出口）

每个正式项目满足下列全部条件方可视为完成：
1. `pnpm content:lint` 0 错误（JSON schema、跨引用、`guide.md` 六项结构、`schematic.svg` 存在且离线有效、故障可注入）。
2. 参考接线通过接线检查（`checkTopology` 0 错误，支持等效星形/链式接法）。
3. 真实 `ngspice` 金标准测试通过：线性电路关键读数相对理论值误差 ≤1%，非线性器件符合数据手册典型趋势（NFR-03）。
4. 数据表（含公式列与合理性提示）与曲线（如有）可正常记录和出图；排故项目全部故障点走通六步状态机。

## 2. 学习资源完成标准（128 个器件/芯片 + 仪表工具 + 概念理论，PRD §8）

每份学习资源位于 `content/learn/<id>/resource.json`（目录名与 `id` 一致），采用 `src/shared/schema/learn.ts` 定义的 `LearnResource` 结构，按五类组织（LRN-01）：

| `category` | 中文分类 | 推荐 ID 前缀 | 3D 模型（`model`） | 内容覆盖重点（PRD LRN-03~08） |
|------------|----------|--------------|--------------------|-------------------------------|
| `component` | 电子元器件（90 个） | `cmp-*` | **必填**（本地 `.glb`） | 覆盖六类必含器件；四项含特性描述、功能参数、安装说明、电路符号、引脚/极性识别、万用表检测方法 |
| `ic` | 常用集成电路（38 个） | `ic-*` | **必填**（复用 DIP `.glb`） | 引脚图/排列、功能表/真值表（GFM 表格）、电气参数、典型应用电路、排查要点 |
| `instrument-tool` | 常用仪器仪表工具 | `ins-learn-*` / `tool-*` | **必填**（本地 `.glb`） | 练习模式全部仪表 + 常用电工工具 3D 认知、面板/部位功能说明、量程规格、安全使用规范 |
| `concept` | 基本概念 | `concept-*` | 可选 | 物理本质、参考方向/符号约定、校核计算公式、实验偏差排查（每项目至少关联 1 份，Q9） |
| `theory` | 基础理论 | `theory-*` | 可选 | 电路分析理论、关键测试节点、核心推导、典型排故速查 |

### 2.1 四项 Markdown 章节门禁（`content:lint`）

`resource.json` 中的 `sections` 对应学习页右侧四个详情 Tab，**每项都必须包含至少一个二级标题（`## <小节标题>`）及实质正文，支持 GFM 表格与 KaTeX 公式，严禁外网媒体 URL（NFR-09）**：

- `sections.structure`（**结构原理**）：内部结构、工作原理、特性描述与安装说明（或芯片功能表）。
- `sections.symbol`（**符号识别**）：电路符号、实物外观、引脚排列/极性识别或仪表/工具面板部位识别。
- `sections.parameters`（**参数计算**）：核心公式、电气参数、选型降额、典型应用电路或量程规格。
- `sections.troubleshooting`（**故障处理**）：万用表离线检测方法、在路排查要点、常见失效模式与安全操作红线。

### 2.2 3D 模型与双向关联约束

- `model` 必须为相对 `content/` 根目录的本地 `.glb` 路径（如 `models/components/cmp-resistor.glb`、`instruments/ins-multimeter/instrument.glb`），不得含 `..` 或外链，文件必须真实存在；同类器件/芯片按 PRD §8.2 复用母版模型降本。
- `relatedInstruments` 与 `relatedModules` 必须填写已存在的仪表 ID 或模块 ID，供实训台一键“查看器件资料”（LRN-08）反向跳转。

## 3. 挂箱模块与器件模型完成标准

每个新增挂箱/实验板模块位于 `content/modules/<mod-id>/`，与 [公共模块运行接口](公共模块运行接口.md) 和 [资产来源与制作](资产来源与制作.md) 配套：

- 目录文件：`module.json`、`module.cir`、`module.glb`、`panel.svg`、`panel.webp`（并在 `assets/layouts/catalog.json` 登记并通过 `pnpm assets:lint`）。
- 端口一致性：`module.cir` 中 `.subckt` 端口顺序与 `module.json` 的 `jacks` 数组 1:1 严格一致；同一铜箔网络通过 `1u` 电阻连接并在 `commonNets` 声明。
- 连续改参（ADR-009）：运行中可调电阻/开关须在 `controls[*].targets` 声明真实电阻元件名，不依赖全网表重载。
- SPICE 模型库（SIM-15）：新增分立器件或芯片子电路放入 `content/models/spice/*.lib`，模块 `.cir` 仅按文件名引用本地库（如 `.lib ttl.lib`），并配套 `tests/golden/models/` 功能表或特性曲线金标准单测。

## 4. 标准模板目录与脚手架命令

标准模板全部位于 `tools/templates/`（随 `tools/content-lint.test.ts` 自动回归验证，确保模板永不漂移）：

| 模板类型 | 模板路径 | 说明 |
|----------|----------|------|
| 实训项目 | `tools/templates/project/DG-00/` | 含完整 `project.json`、`guide.md`、`schematic.svg` |
| 挂箱模块 | `tools/templates/module/mod-template/` | 含 `module.json`、`module.cir`（含 `targets` 与端口注释） |
| 电子元器件 | `tools/templates/learn/cmp-template/resource.json` | 面向 90 个元器件（LRN-03/04/05） |
| 常用集成电路 | `tools/templates/learn/ic-template/resource.json` | 面向 38 个芯片（LRN-06，含功能表 Markdown 表格） |
| 仪表与工具 | `tools/templates/learn/ins-learn-template/resource.json` | 面向全部仪表与工具（LRN-07） |
| 概念与理论 | `tools/templates/learn/concept-template/resource.json` | 面向基本概念与基础理论（LRN-01/02） |

### 4.1 一键生成脚手架（`pnpm content:new`）

脚本入口为 `tools/content-scaffold.ts`，默认写入 `content/`（不覆盖已有目录，显式传 `--force` 才允许覆盖）：

```bash
# 1. 新建实训项目（自动生成 project.json / guide.md / schematic.svg）
pnpm content:new project DG-12 --title "交流电路功率及功率因数的测量" --group "交流电路" --type basic

# 2. 新建电子元器件 / 集成电路 / 仪表工具 / 概念理论学习资源
pnpm content:new learn component cmp-metal-resistor --title "金属膜电阻器" --subcategory "电阻类"
pnpm content:new learn ic ic-cd4511 --title "CD4511 七段锁存译码驱动器" --subcategory "显示译码"
pnpm content:new learn instrument-tool tool-wire-stripper --title "剥线钳" --subcategory "常用电工工具"
pnpm content:new learn concept concept-power-factor --title "交流电路功率因数" --subcategory "交流电路概念"

# 3. 新建挂箱模块（自动同步 .subckt 名与 module.json）
pnpm content:new module mod-ac-power --name "交流功率因数实验挂箱" --form box
```

### 4.2 内容编写提交前自检清单

1. 运行 `pnpm content:lint` —— 确认新增/修改的项目、模块与学习资源全部 0 问题。
2. 运行 `pnpm docs:lint` —— 确认 Markdown 命名规范与本地链接 0 失效。
3. 若新增或修改了挂箱/仪表/器件 GLB 或布局：运行 `pnpm assets:lint`。
4. 若新增或修改了项目拓扑/网表/故障：补充或运行对应 `tests/golden/` 与 `pnpm exec vitest run tools/content-lint.test.ts` 验证读数误差 ≤1% 与故障可注入。
