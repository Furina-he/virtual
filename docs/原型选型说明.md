## 2. 选型结论

**主参照：浙江天煌 DGJ-3 型电工技术实验装置**（控制屏 + 实验桌 + 可更换挂箱），挂箱以天煌 DGJ 系列挂箱为准，天煌官网未公开的细节用同构产品 S2~S6 补齐。

理由：

1. 形态与 PRD 6.1 要求一致：电源控制屏 + 仪表区 + 可更换实验挂箱，挂箱可按项目更换，正好对应 BEN-04“项目启动时自动挂载所需模块”。
2. 国内高校和高职电工实验室装机量大，国内多家厂商的同类产品（S2~S6）在控制屏功能分区、挂箱划分、仪表量程上几乎相同，学员和甲方教师熟悉，“与原型一致”容易被认可。
3. 天煌电路基础挂箱的基尔霍夫/叠加电路（U1、U2、K1~K3、三处电流插座、三个故障按键）是国内教材和指导书里最常见的版本，DG-04/05/08 可直接照搬。
4. DGJ-3 比 DGJ-2 宽一格，凹槽可挂 2 大 2 小挂箱，项目需要同时挂多块模块时（如 DG-09 戴维南 + 元件箱）有余量。

不选 DGJ-2 的原因：凹槽只容 2 大 1 小，部分项目放不下。

建模约束（PRD 6.1）：去除天煌及其他厂商商标与型号丝印；尺寸全部参数化（`content/` 配置），日后按甲方实物替换。

### 5.1 约定

- 插孔 ID 即 GLB 锚点名去掉 `JACK_` 前缀，也是 `.subckt` 端口名（技术设计 §3.1），只用大写字母、数字、下划线，模块内唯一。
- 制作坐标单位 mm，原点在板面左上角，x 向右、y 向下（沿用既有布局表，不依赖 KiCad）；导出 GLB 时由 T0.10 脚本转到 PRD 16.5 坐标系（米、底部安装面中心原点、+Y 向上、正面朝 +Z）。
- 插孔颜色：红 = 电源正 / 输入正，黑 = 电源负 / 地，黄 = 电路节点与测量点，绿 = 电流插座。
- 电流插座：原型为一个常闭插座，插入电流插头后断开、串入电流表。软件中建模为一对绿色插孔（如 `KH_I1A`/`KH_I1B`），模块 JSON 用 `internalJumpers` 默认短接；学员把电流表接到这对插孔上时移除短接（INS-04 “电流插孔/插头”）。具体交互待 T0.11 定。
- 插孔中心距不小于 15 mm（4 mm 香蕉插头外径加手指操作空间）。生成脚本会检查。
- 当前制作源：`assets/layouts/catalog.json`；由 `tools/assets/build.ts` 生成 GLB 与面板。模块插孔契约仍取 `content/modules/<module-id>/module.json`，电路源仍为现有 `.cir`，通过 `pnpm assets:lint` 检查一致性。
- 本节保留首批 3 块面板的既有布局；T0.10 先迁移 `mod-dc-circuit`，`mod-analog-amp` 和 `mod-555-app` 在 T0.15 补齐。表内封装名仅作既有尺寸/外形参考，不要求下载对应 KiCad 库。`assets/kicad/` 下的板文件、`jacks.csv`、`layout.md` 与 `gen_panels.py` 都是历史记录，不直接手改或作为新管线输出覆盖。
