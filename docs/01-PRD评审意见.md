## A. 必须处理（影响架构或工期）

| # | 位置 | 问题 | 建议处理 |
|---|------|------|----------|
| A1 | 14.1 双引擎协同 | "纯数字实验事件驱动快速步进，二者共享网表"暗示要自研第二个数字仿真器，与 6.5"不建议自研"、14.3 自研白名单矛盾 | 只用一个引擎：ngspice + XSPICE 数字原语。真值表遍历也通过 ngspice 驱动。不写第二套数字仿真器（ADR-003） |
| A2 | 6.5 / 8.2 / 13 | **器件模型工作量未列出**。XSPICE 只有门级原语（d_and、d_dff 等），30 个 74LS/CD4000 芯片需要逐个写成子电路（74LS90、192、194、CD4511、CD4060 等较复杂）；分立器件（1N4007、9013/9012、3DG6、BT169、MAC97、DB3、驻极体话筒、气敏、日光灯、电池）和 LM386/NE555/μA741 宏模型需要找来源、核许可证、做验证 | 新增工作包 WP-MODEL：器件模型库 + 每个模型的金标准测试（对照数据手册）。M0 先做 NE555、9013、74LS00、74LS90 四个；量产期与 3D 并行 |
| A3 | SIM-11 / SIM-13 | **实时推进机制没有设计**。ngspice 的 tran 是批处理，不会天然"按真实时间走"；学员拨开关、转电位器发生在仿真进行中；SD-22 要实时出声，音频频段仿真可能跑不过实时 | 见技术设计 §5.4：分片 tran + `bg_halt`/`alter`/`bg_resume`；开关和电位器建成受控元件，避免拓扑变化；音频采用"仿真求周期/包络 + Web Audio 合成"的降级方案。M0 必须用 SD-22、SD-20 实测 |
| A4 | 14.1 高频通道 | "MessagePort 直达渲染进程内存环形缓冲区"在 Electron 下不成立：`utilityProcess` 与渲染进程之间不能共享内存，需主进程用 `MessageChannelMain` 撮合端口，数据以 `Float32Array` 分块转移 | 按技术设计 §4.2 实现：端口直连 + 分块传输 + 渲染端环形缓冲 |
| A5 | 14.2 | 白名单写"锁定"但留了两处二选一：`radix-nova` / `base-nova`，`@dnd-kit/react` / `@dnd-kit/core`。"样式与设计系统"行三个包只给了两个版本 | 选 `radix-nova` + `radix-ui@1.8.1`（shadcn 主线生态）；拖拽选 `@dnd-kit/react@0.5.1`（**需确认**：它仍是 0.x，若要稳妥可改 `@dnd-kit/core@6.3.1`）。`shadcn` 是 CLI，不进运行时依赖 |
| A6 | 15.3 底栏 | "任一面板可拖出为浮动窗口，拖回自动停靠"是一个停靠管理器，白名单里没有库能表达，按 14.3 又不许手写 | 改为"弹出为独立窗口"（新开 Electron `BrowserWindow`，关闭即回到底栏），对双屏投屏更有用，不需要停靠库。**需确认** |
| A7 | 15.3 / INS-01 | 仪表柜在 2D 侧栏，落点在 3D 画布。dnd-kit 的放置目标是 DOM 元素，不能直接识别 3D 台面位置 | 整个 3D 画布作为一个放置目标，松手时用指针坐标射线检测台面的 `SLOT_` 锚点。16.5 锚点表补 `SLOT_<SlotID>` |
| A8 | 14.1 存储 | "SQLite / JSON"未定。SQLite 需要额外原生模块（不在白名单） | 只用 JSON 文件 + zod 校验，存放在用户数据目录（ADR-005） |
| A9 | TSK-06 | 导出 Word 需要 docx 生成库，白名单里没有 | 本期只做 PDF（`printToPDF`），Word 降为 P2，届时再把 `docx` 加入白名单。**需确认** |
| A10 | Q6 / NFR-06 / 15.2 / 16.5 | Q6 默认"课堂投屏不做"，但 NFR-06、15.2 又要求投屏演示模式；Q6 按 GTX 1650 预算，16.5 又说"核显或入门独显" | 演示模式保留（成本低，P1）；性能基线定为 GTX 1650 级，低画质档保证核显 ≥30 FPS（关阴影、降贴图） |
| A11 | 16.5 | "1 单位 = 1 米（或 1 毫米）"二选一未定；"−Z 朝向观察者"与 glTF 惯例（资产正面朝 +Z）相反；`JACK_<NodeID>` 只在单个模块内唯一，多个模块同时挂载会撞名 | 1 单位 = 1 米；+Y 朝上，正面朝 +Z；运行时插孔全局 ID = `<模块实例ID>.<插孔ID>` |
| A12 | 16.1 / 13 | "1 周左右完成全部 3D"不现实：128 个器件/芯片、约 12 块挂箱、6~10 台仪表、5 件工具，还要减面、改材质、挂锚点、去商标。第 13 节没有工期和人力 | 执行计划按资产分批排期，3D 估 4~6 周（1 名技术美术）。总工期见执行计划 |
