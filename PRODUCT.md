# Product

Source: existing PRD sections 1 and 15. This file captures established context, not a new product or visual direction.

## Register

product

## Users

Students in electrical, electromechanical, electronics, and automation programs practice at a 3D training bench. Teachers demonstrate the same workflow on classroom projectors. The interface supports repeated, precise work rather than a marketing or onboarding experience.

## Product Purpose

Complement physical laboratory instruction with circuit recognition, analysis, wiring, measurement, debugging, and fault detection. All 61 planned projects must support wiring, power-on, measurement, recording, and analysis with results consistent with circuit theory and component behavior.

## Brand Personality

Professional, calm, precise. Use textbook terminology and direct action labels. Explain what happened and how to recover without hype or unnecessary courtesy. EDA/IDE tools inform information density; real instruments inform instrument controls. The application frame stays quiet so the bench and measurements remain the focus.

## Anti-references

- Marketing landing pages, oversized headlines, feature-card grids, and decorative illustrations.
- Gradients, glass effects, glow, purple/indigo as a default primary color, or nested cards.
- Decorative emoji/icons, hover lift, staggered list entrances, and motion without functional feedback.
- Promotional claims that replace concrete task status or measurement information.

## Design Principles

- Put the experiment and its current step ahead of navigation and decoration.
- Preserve the established resizable workbench, instrument panels, and shared design tokens.
- Show actual state and measurements; distinguish asset previews from working simulation behavior.
- Keep task actions explicit and errors actionable, using consistent instructional terminology.
- Support both detailed student work and clear teacher projection without separate workflows.

## Accessibility & Inclusion

Retain visible focus and the existing shadcn ARIA behavior. Expose documented keyboard shortcuts in menus/tooltips, and preserve the planned keyboard-accessible wiring-list alternative. Pair electrical colors and state colors with text rather than relying on color alone. Respect reduced-motion preferences. The established light default and enlarged demonstration mode support classroom projection. Follow PRD section 15 for local fonts, sizing, themes, and functional motion; this file does not claim an independently verified WCAG conformance level.
